# T22.3 最小点击区域 — 验证报告

> 任务 T22.3 / 模块 M22 无障碍 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T22.3 实现 `MinTapTarget`（`lib/shared/widgets/min_tap_target.dart`）：在**不改变视觉尺寸**的前提下，把小图标/自定义可点元素的命中区撑到至少 48×48（`kMinInteractiveDimension`），并补齐 `Semantics`（button 角色 + 无障碍标签）。`HitTestBehavior.opaque` 让整块区域（含透明区）可点。4 个 widget 测试全绿。

## 1. 任务目标（来自 spec）

T22.3（spec 888-891）：全局规范 48×48 + 工具组件封装，交付物可点击组件封装。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 最小尺寸 | `ConstrainedBox(minWidth/minHeight: minSize)` + `Center(widthFactor/heightFactor:1)`；默认 `kMinInteractiveDimension`=48 |
| 命中区 | `GestureDetector(behavior: HitTestBehavior.opaque)` 覆盖整块 |
| 语义 | `Semantics(button: onTap!=null, label: semanticLabel, excludeSemantics: ...)` |
| 视觉不变 | child 保持自身尺寸居中显示 |
| 规范 | Material 按钮已内置 padded 命中区，本组件用于自定义可点元素（文档说明） |

## 3. 快速上手（Quick Start）

```dart
MinTapTarget(
  onTap: _onClose,
  semanticLabel: '关闭',
  child: const Icon(Icons.close, size: 16),  // 16px 图标，命中区 48×48
);
```

showcase「M22 无障碍」→「最小点击区域」可见虚线框演示。

## 5. 与 spec 的偏差与决策

T22.3 决策：用 `Center(widthFactor:1)` + `ConstrainedBox` 撑最小尺寸而不撑大 child（视觉不变、命中区变大）；`HitTestBehavior.opaque` 确保图标外透明区也可点。命名与定位强调「补自定义可点元素」，与 Material 按钮自带的 48 命中区不重复。
