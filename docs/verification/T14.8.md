## TL;DR

T14.8 在 `lib/shared/widgets/app_scaffold.dart` 实现 `AppScaffold`：传 `title` 即生成默认 AppBar、`isLoading` 显示带 spinner 的半透明遮罩并拦截点击、默认点空白收起键盘。`flutter analyze` 零问题，单测全绿。

## 1. 任务目标（来自 spec）

T14.8 要求统一 Scaffold 封装：含默认 AppBar、支持加载状态，交付物 `shared/widgets/app_scaffold.dart`（spec 619-625 行）。

## 2. 实际配置

| spec 期望 | 实际实现 |
|---|---|
| 含默认 AppBar | 传 `title`/`titleWidget`/`actions` 自动建 AppBar；`appBar` 可完全自定义；`showAppBar:false` 关闭 |
| 支持加载状态 | `isLoading` → `_LoadingOverlay`（scrim 0.32 + `ModalBarrier` 拦点击 + `LoadingWidget.fullscreen(message)`） |
| 附加 | 默认 `DismissKeyboardOnTap` 包裹 body；`padding`/`bottomNavigationBar`/`floatingActionButton` 透传 |

## 3. 快速上手（Quick Start）

```dart
AppScaffold(
  title: '个人资料',
  actions: [IconButton(icon: const Icon(Icons.edit), onPressed: ...)],
  isLoading: submitting,         // 提交时盖遮罩、防重复点击
  loadingMessage: '提交中…',
  body: form,
);
```

## 5. 与 spec 的偏差与决策

T14.8 关键决策：body 用 `Stack(fit: StackFit.expand)`。否则当 body 是小尺寸 widget 时，Stack 会收缩到内容大小，导致 `Positioned.fill` 的加载遮罩一起塌缩、`LoadingWidget` 溢出。`StackFit.expand` 让 body 充满可用空间，与普通 Scaffold 行为一致。
