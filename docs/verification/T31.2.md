# T31.2 A/B 实验框架 — 验证报告

> 任务 T31.2 / 模块 M31 灰度发布与 A/B Test / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T31.2 实现 A/B 框架：`Variant`/`Experiment`（变体+权重+对照组）模型 + `ExperimentService`（@lazySingleton）`assignFor` 按权重稳定分配变体、`resolve` 处理禁用/回滚回落对照组、`activate` 解析+曝光上报到 M27 `Analytics`（event=experiment_exposure）。8 个单测覆盖（权重分布/边界/禁用回滚/曝光）。

## 1. 任务目标（来自 spec）

T31.2（spec 1121-1126）：实验定义 + 变体分发 + 数据上报，交付物实验框架。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 实验定义 | `Experiment{key, variants, enabled, controlKey}` + `Variant{key, weight}` |
| 变体分发 | `assignFor`：Bucketer 分桶到 `[0, 总权重)` → 按累计权重落变体（稳定可复现） |
| 注册 | `register(experiment)` / `experiment(key)` |
| 数据上报 | `activate`：`Analytics.logEvent('experiment_exposure', {experiment, variant, bucket, forced_control})` |
| 禁用/回滚 | `resolve` 在禁用或回滚时返回对照组（forcedControl=true） |

## 3. 快速上手（Quick Start）

```dart
getIt<ExperimentService>().register(Experiment(
  key: 'button_color',
  variants: const [Variant('control', weight: 50), Variant('blue', weight: 25), Variant('green', weight: 25)],
));
final a = await getIt<ExperimentService>().activate('button_color', unitId); // 取变体 + 上报曝光
```

## 5. 与 spec 的偏差与决策

T31.2 决策：变体分发用「实验 key 作 salt 的稳定分桶 + 累计权重」（可复现、与权重占比一致）；`assignFor` 抽成静态纯函数便于单测分流占比；数据上报复用 M27 Analytics（可切 GA/友盟/神策）；实验定义可由 RemoteConfig（M28）下发，实现免发版调流量。
