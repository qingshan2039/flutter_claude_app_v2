## 2. 设计要点

### 2.1 为何用 ThemeExtension

M3 [ColorScheme] 只有 primary/secondary/error 等角色，**没有** success/warning/info。硬编码这些色值会导致暗色模式失配。ThemeExtension 让业务色：
- 随主题（亮/暗）自动切换
- 主题切换动画时通过 [lerp] 平滑过渡
- 通过 `Theme.of(context).extension<AppColorsExtension>()` 类型安全访问

### 2.2 lerp 实现

```dart
@override
AppColorsExtension lerp(other, double t) {
  if (other is! AppColorsExtension) return this;
  return AppColorsExtension(
    success: Color.lerp(success, other.success, t)!,
    ... // 每个颜色 Color.lerp
  );
}
```

亮↔暗切换时，Flutter 在 `t: 0→1` 间插值，业务色随之渐变（与 M3 角色色一致的过渡体验）。

### 2.3 便捷访问扩展

```dart
extension AppColorsX on BuildContext {
  AppColorsExtension get appColors =>
      Theme.of(this).extension<AppColorsExtension>() ?? AppColorsExtension.light;
}
```

调用点 `context.appColors.success` 比 `Theme.of(context).extension<AppColorsExtension>()!.success` 简洁，且有 null 兜底（无 extension 时回退 light）。
