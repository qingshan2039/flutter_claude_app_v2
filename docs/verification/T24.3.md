# T24.3 账户注销功能 — 验证报告

> 任务 T24.3 / 模块 M24 隐私合规 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T24.3 实现 `AccountDeletionService`（@LazySingleton）：注销进入**冷静期**（默认 7 天，可撤销），到期 `finalizeIfDue()` 触发 `UserDataEraser.eraseAll()`（清 KV + Secure 存储）。冷静期数学是纯静态函数（`isDue`/`daysRemaining`）便于单测。10 个单测全绿（含纯函数 + 流程 + 到期清理）。

## 1. 任务目标（来自 spec）

T24.3（spec 944-948）：注销流程 UI + 冷静期机制 + 数据清理，交付物账户注销模块。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 注销请求 | `requestDeletion()` 存 requestedAt；`pendingRequest()` 读取（含 scheduledAt） |
| 冷静期 | `coolingOff = 7 天`；`isCoolingOff()` / `remainingDays()` |
| 撤销 | `cancelDeletion()`（冷静期内可撤销） |
| 到期清理 | `finalizeIfDue()`：到期 → `UserDataEraser.eraseAll()` + 清请求 |
| 数据清理 | `DefaultUserDataEraser`：`kv.clear()` + `secure.deleteAll()` |
| 纯函数 | `isDue(requestedAt, now, period)` / `daysRemaining(...)` |
| UI | demo 页 + 设置页可接入（发起/撤销/状态） |

## 3. 快速上手（Quick Start）

```dart
await getIt<AccountDeletionService>().requestDeletion();    // 进入冷静期
// 设置页展示剩余天数 + 撤销按钮
await getIt<AccountDeletionService>().cancelDeletion();     // 冷静期内撤销
// App 启动时：
await getIt<AccountDeletionService>().finalizeIfDue();      // 到期清数据
```

## 5. 与 spec 的偏差与决策

T24.3 决策：注销不立即抹除而设**冷静期**（合规 + 防误操作），冷静期数学抽成纯静态函数充分单测；「到期清理」用启动时 `finalizeIfDue()` 触发（无需后台任务）；数据清理抽象 `UserDataEraser`，默认清 KV+Secure，复杂数据（Hive/Isar）按需扩展。
