## 5. 与 spec 的偏差与决策

T01.1 实施过程中出现两处偏差，均因 Flutter 3.41 框架升级而 spec 未同步更新所致。两处偏差均经用户明确确认。

### 5.1 偏差一：Android `minSdk` 从 21 提升至 24

- **spec 期望**: [flutter_template_v3.md:37](file:///Users/ben/Downloads/flutter_template_v3.md) 写「Android minSdk 21」
- **实际值**: `minSdk = flutter.minSdkVersion`，解析为 **24**
- **根因**: Flutter 3.27 起停止支持 Android API 23 以下；Flutter 3.41 的 Gradle 插件常量 `flutter.minSdkVersion` 默认即为 24（源码位置：`/Users/ben/global_software/flutter/packages/flutter_tools/gradle/src/main/kotlin/FlutterExtension.kt:26`，`val minSdkVersion: Int = 24`）
- **额外约束**: Flutter Gradle 插件在每次构建时检测 `build.gradle.kts` 并把硬编码的 `minSdk = 21` 自动改回 `flutter.minSdkVersion`。无法通过普通配置回退至 21。
- **决策**: 用户确认采用 24，与 Flutter 3.41 框架对齐。

### 5.2 偏差二：iOS `IPHONEOS_DEPLOYMENT_TARGET` 从 12.0 提升至 13.0

- **spec 期望**: [flutter_template_v3.md:38](file:///Users/ben/Downloads/flutter_template_v3.md) 写「iOS 最低 12.0」
- **实际值**: `IPHONEOS_DEPLOYMENT_TARGET = 13.0`（出现于 `ios/Runner.xcodeproj/project.pbxproj` 三处 build configuration）
- **根因**: Flutter 3.27 起停止支持 iOS 12；Flutter 3.41 模板默认 `IPHONEOS_DEPLOYMENT_TARGET = 13.0`（模板源码：`/Users/ben/global_software/flutter/packages/flutter_tools/templates/app/ios.tmpl/Runner.xcodeproj/project.pbxproj.tmpl`）
- **决策**: 用户确认采用 13.0，与 Flutter 3.41 框架对齐。

### 5.3 建议

建议把 [flutter_template_v3.md:37-38](file:///Users/ben/Downloads/flutter_template_v3.md) 中的 `Android minSdk 21` 与 `iOS 最低 12.0` 更新为 `24` 与 `13.0`，避免后续模块（如 M16 CI/CD、M18 安全规范、M22 无障碍）实施时再次踩到同样的版本冲突。
