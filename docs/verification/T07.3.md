## 2. 设计要点

### 2.1 StatefulShellRoute 而非 ShellRoute

| 方案 | 跨 branch 切换时 |
|---|---|
| `ShellRoute` | 整个 child 重建（丢失 ListView 滚动位置等） |
| `StatefulShellRoute.indexedStack` | 各 branch 独立 Navigator，状态完整保留 |

模板用 `StatefulShellRoute.indexedStack`，符合现代 app 用户预期。

### 2.2 ScaffoldWithNavBar 单一职责

只负责画 [NavigationBar] 和处理 `goBranch` 调度；branch 内的路由栈完全由 go_router 管理。

```dart
class ScaffoldWithNavBar extends StatelessWidget {
  ScaffoldWithNavBar({required this.navigationShell});
  final StatefulNavigationShell navigationShell;

  void _onTap(int index) {
    navigationShell.goBranch(
      index,
      // 再次点击当前 tab → 回到 branch 根（pop 全部）
      initialLocation: index == navigationShell.currentIndex,
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: navigationShell,
      bottomNavigationBar: NavigationBar(
        selectedIndex: navigationShell.currentIndex,
        onDestinationSelected: _onTap,
        destinations: [...],
      ),
    );
  }
}
```

### 2.3 Detail 跳出 Shell

```dart
GoRoute(
  path: '/detail/:id',
  parentNavigatorKey: rootKey,   // ← 关键：用 root 而非 shell key
  ...
)
```

效果：从 Home 点击「Open detail #42」推入详情页时，**BottomNavigationBar 消失**（详情页占满全屏）。
