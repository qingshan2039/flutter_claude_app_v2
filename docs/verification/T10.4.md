## 2. 设计要点

### 2.1 重构：共享 keyValueStorageProvider

T08 把 `keyValueStorageProvider`（getIt<KeyValueStorage> 桥接）放在 `i18n/locale_provider.dart`。T10 主题持久化也需要它，但 theme 不应依赖 i18n。重构：

```
lib/core/storage/storage_providers.dart   ← keyValueStorageProvider 新家（共享）
  ↑ import                ↑ import
i18n/locale_provider.dart  theme/theme_mode_provider.dart
```

`locale_provider.dart` 加 `export ... show keyValueStorageProvider` 让既有 import（含 T08 测试）零改动继续工作。

### 2.2 ThemeMode 持久化

```dart
class ThemeModeNotifier extends Notifier<ThemeMode> {
  @override
  ThemeMode build() => _parse(ref.read(keyValueStorageProvider).getString(storageKey));

  Future<void> setThemeMode(ThemeMode mode) async {
    await ref.read(keyValueStorageProvider).setString(storageKey, mode.name);
    state = mode;
  }
}
```

`mode.name`（'system'/'light'/'dark'）作为持久化值；`_parse` 反向解析，非法值回退 system。

### 2.3 MaterialApp 绑定（即时生效）

```dart
MaterialApp(
  theme: AppTheme.light,
  darkTheme: AppTheme.dark,
  themeMode: ref.watch(themeModeProvider),
);
```

`ref.watch` → 切换 mode 即重建 MaterialApp，主题立即应用（含 ThemeExtension lerp 过渡动画）。

### 2.4 toggle 便捷方法

`toggle()` 在 light/dark 间快速切（dark→light，否则→dark），用于一键明暗开关 UI。
