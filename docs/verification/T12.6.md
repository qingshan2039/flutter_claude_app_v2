## 2. 设计要点

### 2.1 viewPadding（非 padding）

```dart
static double bottomInset(BuildContext context) => MediaQuery.viewPaddingOf(context).bottom;
```

用 `viewPadding`（系统 UI 占用，键盘弹出前的稳定值）而非 `padding`（键盘弹出会变 0）。Home Indicator 避让用 viewPadding 才稳定。

### 2.2 AppSafeArea 项目规范

默认：上下避让、左右贴边（多数页面横向已贴边）、支持 `minimum` 兜底留白。统一封装让全项目 SafeArea 行为一致，避免每页手写。

### 2.3 文档规范（RESPONSIVE.md §6）

- 页面根用 AppSafeArea（或 Scaffold 自带）
- 全屏背景铺满，内容用 SafeArea
- 底部固定按钮额外加 bottomInset 避开 Home Indicator
- viewPadding vs padding 的区别
