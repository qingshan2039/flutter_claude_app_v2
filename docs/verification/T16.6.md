## TL;DR

T16.6 配置三层混淆/压缩：Android R8（release `isMinifyEnabled` + `isShrinkResources` + `proguard-rules.pro`）+ Dart 层 `--obfuscate --split-debug-info`（产符号供崩溃还原）+ iOS dSYM 上传（fastlane `:upload_symbols`）。已实跑 release 构建验证不被 R8 破坏。

## 1. 任务目标（来自 spec）

T16.6（spec 663-667）：Android ProGuard/R8 规则、iOS symbol 上传，交付物混淆配置文件 + 文档。

## 2. 实际配置

| 层 | 配置 |
|---|---|
| Android R8 | `build.gradle.kts` release：`isMinifyEnabled=true` + `isShrinkResources=true` + `proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")` |
| ProGuard 规则 | `android/app/proguard-rules.pro`：keep Flutter 引擎/插件、保留行号、@Keep 兜底 |
| Dart 混淆 | 打包脚本统一 `--obfuscate --split-debug-info=build/symbols/<flavor>` |
| iOS 符号 | fastlane `:upload_symbols`（sentry-cli 上传 dSYM/symbols） |

## 5. 与 spec 的偏差与决策

T16.6 决策：(1) R8 在 release **默认开启**（生产级），并实跑验证不破坏构建——多数原生插件（sentry / permission_handler / flutter_secure_storage 等）随包带 consumer-proguard 规则，故自定义规则只需补 Flutter 引擎 keep 与行号保留。(2) Dart 混淆与符号拆分统一进打包脚本；符号是崩溃还原前提，**务必随版本留存/上传**。(3) iOS dSYM 上传走 fastlane lane（需 sentry-cli + 凭据），文档化。
