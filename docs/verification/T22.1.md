# T22.1 Semantics 规范 — 验证报告

> 任务 T22.1 / 模块 M22 无障碍 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T22.1 新建 `docs/accessibility/ACCESSIBILITY.md`（无障碍总规范：Semantics 用法 + 语义标签规范 + 对比度/点击区域/焦点/字体缩放/测试）；并为**关键组件** `AppImage` 新增 `semanticLabel`（→ `Semantics(image: true, label: ...)`）。语义标签规范明确「标签是读给人听的话、不写控件类型、状态用语义属性、装饰图不朗读」等约定。

## 1. 任务目标（来自 spec）

T22.1（spec 878-881）：关键组件添加 Semantics + 语义标签规范，交付物 a11y 规范文档。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 规范文档 | `docs/accessibility/ACCESSIBILITY.md`（4 主线：语义/对比度/点击区域/焦点 + 字体缩放 + 测试） |
| 语义标签规范 | label 是人话、不写控件类型、状态用 selected/toggled/disabled、装饰图不加 label、header/liveRegion、随 i18n |
| 关键组件加语义 | `AppImage.semanticLabel` → `Semantics(image:true,label:)`；`MinTapTarget`（T22.3）button+label |
| 必加语义场景表 | 纯图标按钮 / 有意义图片 / 自绘控件 / MergeSemantics / ExcludeSemantics / liveRegion |

## 3. 快速上手（Quick Start）

```dart
AppImage(url, semanticLabel: '产品封面');                 // 有意义的图片
Semantics(button: true, label: '收藏', child: customTap); // 自绘可点元素
MergeSemantics(child: Row(children: [icon, text]));       // 合并连读
```

阅读 [docs/accessibility/ACCESSIBILITY.md](../accessibility/ACCESSIBILITY.md)。
