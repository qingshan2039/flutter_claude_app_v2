# T29.4 网络抓包 — 验证报告

> 任务 T29.4 / 模块 M29 内置 Debug 面板 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T29.4 实现 `NetworkInspector`（@lazySingleton 环形缓冲，最新在前）+ `NetworkRecord`（fromResponse/fromError 映射方法/URL/状态/耗时/请求响应体，4xx/异常判为 error）+ `NetworkInspectorInterceptor`（Dio 拦截器，记请求耗时与结果）。Debug 面板「网络」Tab 展示请求历史。6 个单测全绿。

## 1. 任务目标（来自 spec）

T29.4（spec 1078-1081）：请求历史查看 + 请求/响应详情，交付物网络面板。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 记录 | `NetworkRecord{method,url,statusCode,durationMs,requestBody,responseBody,error}`（体截断 2000 字符） |
| 工厂 | `fromResponse(Response, durationMs)` / `fromError(DioException, durationMs)` |
| 错误判定 | `isError`：有 error 或 statusCode≥400 |
| 缓冲 | 环形（capacity 100），`records` 最新在前 |
| 拦截器 | `NetworkInspectorInterceptor`：onRequest 记起始、onResponse/onError 记录 + 耗时 |
| 接入 | `dio.interceptors.add(NetworkInspectorInterceptor(getIt<NetworkInspector>()))`（文档化） |

## 3. 快速上手（Quick Start）

```dart
dio.interceptors.add(NetworkInspectorInterceptor(getIt<NetworkInspector>()));
// Debug 面板「网络」Tab 即可看到历史请求。
```
