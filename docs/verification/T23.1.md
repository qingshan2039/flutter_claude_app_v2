# T23.1 版本检查接口 — 验证报告

> 任务 T23.1 / 模块 M23 应用内更新 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T23.1 实现版本检查模块：`AppVersion`（SemVer 宽松解析 + 数值比较运算符）、`UpdateInfo`/`UpdatePolicy`/`UpdateDecision` 模型（含 `fromJson` 后端契约）、`VersionCheckService`（抽象 + `@LazySingleton` stub）、`UpdateManager`（`decide` 纯决策 + `check` 拉取后端）。DI 注册 VersionCheckService/UpdateManager，20 个单测全绿。

## 1. 任务目标（来自 spec）

T23.1（spec 906-909）：后端版本检查 API 对接 + 版本号比较工具，交付物版本检查模块。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 版本号比较 | `AppVersion.parse`（容忍前导 v/缺省段/build）+ `</<=/>/>=/==/compareTo`，按数值（1.9 < 1.10） |
| 后端契约 | `UpdateInfo.fromJson`（latestVersion/minSupportedVersion/releaseNotes/storeUrl/apkUrl/preferSilent） |
| 服务 | `VersionCheckService`（抽象）→ `StubVersionCheckService`（@LazySingleton，注释含真实 Dio 实现示例） |
| 决策 | `UpdateManager.decide`（纯函数）+ `check`（拉后端再决策），@lazySingleton 注入 service |

## 3. 快速上手（Quick Start）

```dart
final decision = getIt<UpdateManager>().decide(
  current: AppVersion.parse('1.3.0'),
  info: await getIt<VersionCheckService>().fetchLatest(),
);
// decision.policy ∈ {upToDate, silent, optional, force}
```

T23.1 决策：版本解析**宽松**（非法段按 0，宁降级不崩溃）；后端对接以接口 + stub 形式交付，stub 注释给出真实 Dio 实现，DI 一行切换；`decide` 与 `check` 分离，使核心策略可纯函数单测（不依赖网络）。
