# T16.5 iOS 打包脚本 — 验证报告

## TL;DR

T16.5 新增 `scripts/build_ios.sh <flavor> [ipa|testflight]` 与 `ios/fastlane/{Fastfile,Appfile}`：`ipa` 直接 `flutter build ipa`（带混淆符号）；`testflight` 走 fastlane `:beta` lane 构建并上传 TestFlight。

## 1. 任务目标（来自 spec）

T16.5（spec 657-661）：fastlane 配置、TestFlight 上传，交付物 `scripts/build_ios.sh` + Fastfile。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 构建 | `flutter build ipa --flavor <env> -t lib/main_<env>.dart --release --obfuscate --split-debug-info` |
| TestFlight | fastlane `:beta`：Flutter 出 ipa → `upload_to_testflight`（App Store Connect API Key 走环境变量） |
| 符号 | fastlane `:upload_symbols`：sentry-cli 上传 dSYM（T16.6） |
| 凭据安全 | Appfile 用环境变量；ASC API Key（.p8）不入库 |

## 3. 快速上手（Quick Start）

```bash
scripts/build_ios.sh prod ipa            # 仅构建 .ipa
scripts/build_ios.sh prod testflight     # 构建并上传 TestFlight
```

T16.5 决策：iOS 发布强依赖 macOS/Xcode/Apple 凭据与 scheme 配置（见 `docs/env/ENVIRONMENTS.md` 的 iOS flavor 一节），故本任务交付脚本 + fastlane 配置 + 文档，不在本环境实跑。所有密钥经环境变量/CI Secrets 注入，绝不入库。
