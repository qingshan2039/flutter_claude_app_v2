## 3. 设计要点

### 3.1 抽象 AppDatabase + 实现 HiveAppDatabase

```dart
abstract class AppDatabase {
  List<String> get recentQueries;
  Future<void> addRecentQuery(String query);
  Future<void> clearRecentQueries();
  Future<void> close();
}

class HiveAppDatabase implements AppDatabase {
  HiveAppDatabase(this._recentQueriesBox);   // 构造公开，便于测试直接传 box
  final Box<String> _recentQueriesBox;
  ...
}
```

### 3.2 @module 模式 + @preResolve

```dart
@module
abstract class DatabaseModule {
  @preResolve
  @lazySingleton
  Future<AppDatabase> provideAppDatabase() async {
    await Hive.initFlutter();
    final migrator = DatabaseMigrator(targetVersion: 1, migrations: [(_) async {}]);
    await migrator.runIfNeeded();
    final box = await Hive.openBox<String>(HiveAppDatabase.recentQueriesBoxName);
    return HiveAppDatabase(box);
  }
}
```

- `Hive.initFlutter()` 异步初始化（内部用 path_provider 找 documents 目录）
- `DatabaseMigrator.runIfNeeded()` 在打开业务 box **之前** 执行（数据迁移先于使用）
- 业务 box 用 `openBox<String>` 强类型

### 3.3 未引入 hive_generator

`hive_generator` 用于生成 `@HiveType` 类的 type adapter。本任务只演示 `Box<String>`（原生类型），无需 adapter。后续业务若需存储自定义类型（如 `RecentQuery` 数据类），按以下步骤接入：

1. 在 `pubspec.yaml dev_dependencies` 加 `hive_ce_generator`
2. 写 `@HiveType(typeId: 0) class RecentQuery { ... }` + part `recent_query.g.dart`
3. `dart run build_runner build` 生成 adapter
4. 在 `provideAppDatabase` 中 `Hive.registerAdapter(RecentQueryAdapter())` 后再 openBox
