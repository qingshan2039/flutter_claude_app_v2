# T24.5 隐私政策与用户协议页 — 验证报告

> 任务 T24.5 / 模块 M24 隐私合规 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T24.5 实现 `LegalDocument`/`LegalSection` 模型（含 **version + effectiveDate** 版本管理）+ 内置 `kPrivacyPolicy`/`kUserAgreement`（带版本常量）+ `LegalDocumentPage`（结构化富文本渲染：版本/生效日期头 + 章节标题/正文）。2 个 widget 测试全绿。

## 1. 任务目标（来自 spec）

T24.5（spec 955-958）：富文本展示 + 版本管理，交付物协议页面。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 模型 | `LegalDocument{title, version, effectiveDate, sections}` + `LegalSection{heading, body}` |
| 版本管理 | `kPrivacyPolicyVersion`/`kUserAgreementVersion` 常量；政策升版本配合 `ConsentStore` 重新同意（T24.1） |
| 内置文档 | `kPrivacyPolicy`/`kUserAgreement`（占位内容，上线前法务定稿替换） |
| 富文本 | `LegalDocumentPage`：标题/正文分层样式渲染（可扩展 markdown/flutter_html） |
| 头部 | 「版本 x · 生效日期 yyyy-MM-dd」 |

## 3. 快速上手（Quick Start）

```dart
Navigator.of(context).push(MaterialPageRoute(
  builder: (_) => const LegalDocumentPage(document: kPrivacyPolicy),
));
```

showcase「M24 隐私合规」→「协议页」可打开隐私政策/用户协议。

## 5. 与 spec 的偏差与决策

T24.5 决策：富文本用「结构化章节（标题+段落）」而非引入 markdown/flutter_html 依赖（保持零额外依赖，需要时易扩展）；版本号抽成常量供 `ConsentStore`（T24.1）比对，把「政策更新→重新同意」串成闭环；内置内容为占位，明确标注上线前替换为法务定稿。
