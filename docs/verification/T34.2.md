# T34.2 页面转场动画 — 验证报告

> 任务 T34.2 / 模块 M34 动效系统 / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T34.2 交付命令式导航的统一转场封装 `AppTransitions`：枚举 `AppTransitionType{fade, slideUp, scale, sharedAxis}` + `build()` 返回对应过渡 widget（取 `MotionTokens.emphasized` 曲线）+ `route<T>()` 直接产出带统一转场的 `PageRoute`（默认时长 `MotionTokens.normal`）。与 M07/T07.7 go_router 的 `PageTransitions` 视觉语言一致，互补覆盖声明式/命令式两种导航。4 个单测全绿。

## 1. 任务目标（来自 spec）

T34.2（spec 1179-1181）：统一转场封装，交付物转场组件。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 类型 | `AppTransitionType{fade, slideUp, scale, sharedAxis}` |
| 过渡构建 | `build(type, animation, child)`：switch 表达式返回 Fade/Slide/Scale 组合（含淡入） |
| 曲线/反向 | `CurvedAnimation(curve: emphasized, reverseCurve: emphasizedAccelerate)` |
| 路由工厂 | `route<T>({builder, type=fade, duration=normal, settings})` → `PageRouteBuilder` |
| 关系 | 命令式（Navigator.push）；go_router 转场仍用 `PageTransitions`（T07.7） |

## 3. 快速上手（Quick Start）

```dart
Navigator.of(context).push(
  AppTransitions.route<void>(
    type: AppTransitionType.slideUp,
    builder: (_) => const DetailPage(),
  ),
);
```

测试覆盖（`app_transitions_test.dart`，含 3 项）：fade→FadeTransition（无 SlideTransition）、slideUp/sharedAxis→SlideTransition、scale→ScaleTransition（裸 Directionality 下计数，避开路由默认转场噪声）；`route` 默认时长 = `MotionTokens.normal`；`route` 实际可推入目标页。

## 5. 与 spec 的偏差与决策

T34.2 决策：（1）`AppTransitions` 面向**命令式 Navigator**，与 T07.7 的 go_router `PageTransitions`（`CustomTransitionPage`）分工互补、共享 `MotionTokens` 节奏，不重写既有路由代码降低回归风险；（2）`build` 用 Dart 3 switch 表达式覆盖全部枚举（编译期穷尽）；（3）每种转场都叠加淡入，过渡更柔和统一。组件测试在裸 `Directionality` 下断言，避免 `MaterialApp` 路由自带的默认转场（含多个 SlideTransition）污染计数。
