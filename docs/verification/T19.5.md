# T19.5 权限演示页 — 验证报告

> 任务 T19.5 / 模块 M19 示例业务模块 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T19.5 在 `features/permission_demo/` 落地权限演示页：复用 M09 `PermissionService` / `PermissionGuide`，对 `AppPermission.values`（相机/相册/麦克风/定位/通知/存储/蓝牙）逐权限「请求」并展示状态；被永久拒绝（`status.needsSettings`）时弹 `PermissionGuide.showSettingsDialog` 引导跳系统设置；另含一站式 `ensureGranted`（含 rationale + 永久拒绝引导）演示。由设置页 `/permissions` 进入（root navigator）。验收：analyze 0 issue、test 全绿、dev APK 构建成功。

## 1. 任务目标（来自 spec）

T19.5（spec 787-790）：权限演示页需覆盖**各权限请求、永久拒绝引导**，交付物 `features/permission_demo/`。

## 2. 实际配置

| 关注点 | 实现 |
|---|---|
| 各权限请求 | `for (p in AppPermission.values)` 渲染 Card+ListTile，`FilledButton`「请求」→ `_service.request(p)`，subtitle 显示 `AppPermissionStatus.name`（未请求/granted/denied/...） |
| 永久拒绝引导 | `_request` 后若 `status.needsSettings` → `PermissionGuide.showSettingsDialog(context, ..., service: _service)` 引导跳系统设置 |
| 一站式 | `_ensureCamera` → `_guide.ensureGranted(context, camera, rationaleTitle/Message...)`，结果 SnackBar 反馈 |
| 入口 | 设置页 ListTile → `context.goNamed(RouteNames.permissions)`；`/permissions` 路由 `parentNavigatorKey: rootKey` |
| 复用 | M09 `PermissionService`（getIt）+ `PermissionGuide` |

## 3. 快速上手（Quick Start）

```bash
flutter run -t lib/main_dev.dart --flavor dev   # 设置页 →「权限演示」→ 逐权限「请求」（真机/模拟器弹原生授权框）
```

被永久拒绝后再点请求会弹「需要 X 权限」对话框，确认即跳系统设置页。

T19.5 决策：完全复用 M09 的 `PermissionService` / `PermissionGuide`，不在业务页重写权限逻辑，验证 M09 封装可直接支撑业务页；权限的真实弹框行为依赖真机/模拟器（host 上 permission_handler 不弹框），故本任务以「构建通过 + 逻辑接线正确」为验收口径，行为验证留待真机。
