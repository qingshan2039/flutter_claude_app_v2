## 2. 设计要点

### 2.1 公开 API

| API | 用途 |
|---|---|
| `acquire(key, {replacedReason})` | 为 key 创建 CancelToken；若 key 已有 token 则自动取消旧的 |
| `cancel(key, {reason})` | 取消并移除 key 关联的 token |
| `cancelAll({reason})` | 取消所有 token（登出场景） |
| `activeCount` | 当前活跃 token 数量（不含已取消） |
| `hasToken(key)` | 是否有 key 在册（调试/测试用） |

### 2.2 key 用 Object 而非 String

`key` 类型是 `Object`，可以是 Provider ref、Widget hashCode、enum、字符串……不强制业务用某种类型，调用方便。

### 2.3 acquire 自动取消旧 token

```dart
CancelToken acquire(Object key, {String? replacedReason}) {
  cancel(key, reason: replacedReason ?? 'Replaced by new acquire');
  final token = CancelToken();
  _tokens[key] = token;
  return token;
}
```

典型场景：用户在搜索框快速打字，每次 keystroke 都触发新请求。同一 key 重 acquire → 旧请求取消，仅最后一个生效。

### 2.4 Riverpod autoDispose 联动（M06 后接入）

```dart
final searchProvider = FutureProvider.autoDispose.family<List<Item>, String>((ref, query) async {
  final manager = getIt<CancelTokenManager>();
  final token = manager.acquire(ref);
  ref.onDispose(() => manager.cancel(ref, reason: 'provider disposed'));
  return repo.search(query, cancelToken: token);
});
```

`ref` 作为 key 利用了 Riverpod ref 的引用同一性。
