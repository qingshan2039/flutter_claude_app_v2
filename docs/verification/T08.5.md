## TL;DR

T08.5 让 [LocaleNotifier](file:///Users/ben/ai_project/flutter_claude_app_v2/lib/core/i18n/locale_provider.dart) 把语言选择持久化到 [KeyValueStorage]（T05.1 SharedPreferences），key `app.locale`。`build()` 启动时读取（无值 → `null` 跟随系统）；`setLocale` 写入 / `setLocale(null)` 移除。复用 T05.1 的存储层，不引入新依赖。7 条测试覆盖读写、移除、连续切换。

## 1. 任务目标（spec）

- 写入 SharedPreferences
- 启动时读取
- 首次启动跟随系统语言
- **交付物**：完整持久化逻辑

## 2. 设计要点

### 2.1 三态持久化逻辑

| 场景 | storage 行为 | state |
|---|---|---|
| 首次启动（无值） | `getString('app.locale')` → null | `null`（跟随系统） |
| 选择 zh | `setString('app.locale', 'zh')` | `Locale('zh')` |
| 恢复跟随系统 | `remove('app.locale')` | `null` |

### 2.2 build() 启动读取

```dart
@override
Locale? build() {
  final storage = ref.read(keyValueStorageProvider);
  final code = storage.getString(storageKey);
  if (code == null || code.isEmpty) return null;   // 首次 → 跟随系统
  return Locale(code);
}
```

### 2.3 setLocale 写入

```dart
Future<void> setLocale(Locale? locale) async {
  final storage = ref.read(keyValueStorageProvider);
  if (locale == null) {
    await storage.remove(storageKey);
  } else {
    await storage.setString(storageKey, locale.languageCode);
  }
  state = locale;
}
```

### 2.4 复用 T05.1 KeyValueStorage

不直接用 SharedPreferences；用抽象 [KeyValueStorage]（T05.1）。好处：
- 桌面端可换 Hive 实现
- 测试用 `_FakeKeyValueStorage` 注入（无平台 channel 依赖）

### 2.5 桥接 provider 便于测试

```dart
final keyValueStorageProvider = Provider<KeyValueStorage>(
  (ref) => getIt<KeyValueStorage>(),
);
```

测试 override 此 provider 注入内存 fake，无需碰 getIt 全局容器。

## 4. 关键测试断言

// 有持久化值 → 读取
storage._store['app.locale'] = 'zh';
