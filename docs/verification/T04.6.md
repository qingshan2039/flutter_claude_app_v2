## 2. 实现

### 2.1 接口定义

```dart
@RestApi()
abstract class ExampleApiService {
  factory ExampleApiService(Dio dio, {String? baseUrl}) = _ExampleApiService;

  @GET('/users/{id}')
  Future<UserModel> getUserById(@Path('id') String id);

  @POST('/users')
  Future<UserModel> createUser(@Body() UserModel user);

  @PUT('/users/{id}')
  Future<UserModel> updateUser(@Path('id') String id, @Body() UserModel user);

  @DELETE('/users/{id}')
  Future<void> deleteUser(@Path('id') String id);
}
```

### 2.2 DI 注册

```dart
@module
abstract class ExampleApiModule {
  @lazySingleton
  ExampleApiService exampleApi(Dio dio) => ExampleApiService(dio);
}
```

### 2.3 生成代码骨架

`api_service.g.dart` 实现 `_ExampleApiService`，每个方法做：
1. 构造 `_path` + path 参数替换
2. 用 `_dio.fetch<Map<String, dynamic>>(...)` 发起请求（自动走所有拦截器链）
3. 用 `UserModel.fromJson` 反序列化

## 3. 版本约束修复
