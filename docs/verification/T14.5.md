# T14.5 Toast / Dialog 工具 — 验证报告

> 任务 T14.5 / 模块 M14 通用 UI 组件 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T14.5 在 `lib/shared/utils/overlay_utils.dart` 实现 `OverlayService`（`@lazySingleton`），持有全局 `scaffoldMessengerKey` + `navigatorKey`，**脱离 BuildContext** 弹 Toast（floating SnackBar，按 ToastType 配色）与 Dialog（统一 AlertDialog + `showConfirm`）。两个 Key 已接入 `app.dart`（go_router rootNavigatorKey + scaffoldMessengerKey）与 `showcase_app.dart`。

## 1. 任务目标（来自 spec）

T14.5 要求 Toast / Dialog 工具：脱离 BuildContext 调用、统一样式，交付物 `shared/utils/overlay_utils.dart`（spec 604-608 行）。

## 2. 实际配置

| spec 期望 | 实际实现 |
|---|---|
| 脱离 BuildContext | `OverlayService` 持 `GlobalKey<ScaffoldMessengerState>` + `GlobalKey<NavigatorState>`；接入 MaterialApp |
| 统一样式 Toast | `showToast/showSuccess/showError/showWarning/showInfo`：floating + 圆角 + 语义色（取 `context.appColors` M10 业务色）+ 图标 |
| 统一样式 Dialog | `showAppDialog<T>`（AlertDialog + TextButton actions）+ `showConfirm`（确认/取消，destructive 用错误色） |
| DI 注册 | `@lazySingleton`；`getIt<OverlayService>()` |

## 3. 快速上手（Quick Start）

```dart
// 拦截器/Service/Notifier 内无 context 也能用：
getIt<OverlayService>().showError('网络异常');
final ok = await getIt<OverlayService>().showConfirm(
  title: '删除？', confirmLabel: '删除', destructive: true);

// 接线（已完成）：
// app.dart   → MaterialApp.router(scaffoldMessengerKey: ..., 并把 navigatorKey 传给 createAppRouter(rootNavigatorKey:))
// showcase_app.dart → MaterialApp(scaffoldMessengerKey:..., navigatorKey:...)
```

## 5. 与 spec 的偏差与决策

T14.5 决策：(1) Dialog 的 actions 一律用 `TextButton`（Material 对话框规范），同时规避主题给 `FilledButton/OutlinedButton` 设的 `minimumSize: Size.fromHeight(48)` 在 `OverflowBar` 中触发的「无限宽度」断言。(2) go_router 自管根 Navigator——故让 `createAppRouter` 接受可选 `rootNavigatorKey`，把 `OverlayService.navigatorKey` 注入，使主 App 也能脱离 context 弹窗。(3) Toast 配色取 M10 的 `AppColorsExtension`（success/warning/info），无该扩展时回退 light。
