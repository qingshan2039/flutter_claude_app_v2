## 2. 设计要点

### 2.1 背景与图标相反

状态栏图标必须与背景对比才看得清：

| 背景（主题） | 状态栏图标 |
|---|---|
| 浅色（light） | 深色图标（Brightness.dark icons） |
| 深色（dark） | 浅色图标（Brightness.light icons） |

### 2.2 iOS/Android 字段差异

```dart
SystemUiOverlayStyle(
  statusBarColor: Colors.transparent,
  statusBarIconBrightness: ...,        // Android：图标亮度
  statusBarBrightness: backgroundBrightness, // iOS：状态栏「背景」亮度语义
  systemNavigationBarColor: ...,
  systemNavigationBarIconBrightness: ...,
);
```

iOS 与 Android 对「brightness」语义不同（一个指图标、一个指背景），本工具两端都设，保证跨端一致。

### 2.3 纯函数 + Widget 分离

- `AppStatusBar.styleFor(Brightness)`：纯函数，**易测**（无需 widget tree）
- `ThemedStatusBar`：消费 `Theme.of(context).brightness` → 调 styleFor → 包 AnnotatedRegion

分离让逻辑单测（4 条）与 widget 集成测（2 条）各司其职。

### 2.4 用法

```dart
// 页面根或 Scaffold 外层
ThemedStatusBar(child: Scaffold(...));
```

主题切到 dark → `Theme.of(context).brightness` 变 dark → 状态栏图标自动转浅色。
