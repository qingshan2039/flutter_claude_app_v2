## 2. 设计要点

### 2.1 锁定方向

```dart
enum OrientationLockMode { portrait, landscape, all }

static List<DeviceOrientation> orientationsFor(OrientationLockMode mode) => switch (mode) {
  OrientationLockMode.portrait => [portraitUp, portraitDown],
  OrientationLockMode.landscape => [landscapeLeft, landscapeRight],
  OrientationLockMode.all => DeviceOrientation.values,
};

static Future<void> lockPortrait() => SystemChrome.setPreferredOrientations(orientationsFor(portrait));
```

把方向映射抽成纯函数 `orientationsFor`，可单测；`lock/unlock` 委托 SystemChrome。

### 2.2 状态保留（文档说明）

横竖屏切换时 Flutter **不重建 State 对象**：
- StatefulWidget 字段（选中项/表单值）自动保留
- 滚动位置：ScrollView 加 `PageStorageKey` 跨方向保留
- TextField：`TextEditingController` 持有文本

无需手写「保存/恢复」逻辑。详见 RESPONSIVE.md §7。
