## TL;DR

T17.1 给 auth 切片引入 `AuthRemoteDataSource`（seam），把 Repository 重构为
「DataSource → Model → Mapper → Entity + 错误归一化」分层；新增

## 5. 与 spec 的偏差与决策

T17.1 决策：原 `AuthRepositoryImpl` 是内联 stub（无数据源），无法演示「mock DataSource」。故引入 `AuthRemoteDataSource` seam（DataSource 只取原始 Model、抛异常；Repository 负责 mapper + 错误归一化）。这让架构更真实、Mapper 进入真实调用链，且给 Repository 测试提供 mock 目标。重构经 build_runner 重新注册 DI，既有测试（含 `current_user_provider` 端到端）仍全绿。
