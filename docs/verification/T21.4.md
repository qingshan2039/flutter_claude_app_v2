# T21.4 图片性能 — 验证报告

> 任务 T21.4 / 模块 M21 性能优化体系 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T21.4 扩展 M14 的 `AppImage`：新增 `cacheWidth/cacheHeight`（逻辑像素，build 时按 `devicePixelRatio` 换算成 `memCacheWidth/Height` 控制**解码内存**）、`maxWidthDiskCache/maxHeightDiskCache`（磁盘缓存原图尺寸），以及 `AppImage.thumbnail` 构造（**缩略图与原图分离**：按展示尺寸解码 + 磁盘缓存限制到 2×size）。`circle` 头像也默认限制解码尺寸。新增 4 个 widget 测试。

## 1. 任务目标（来自 spec）

T21.4（spec 858-861）：缩略图与原图分离 + 内存缓存控制，交付物图片优化配置。

## 2. 实际配置

| 能力 | 实现 |
|---|---|
| 内存缓存控制 | `cacheWidth/Height`（逻辑 px）→ `(logical * dpr).round()` → `memCacheWidth/Height` |
| 磁盘缓存控制 | `maxWidthDiskCache/maxHeightDiskCache`（原始 px）透传 CachedNetworkImage |
| 缩略图/原图分离 | `AppImage.thumbnail(url, size)`：memCache=size·dpr、磁盘=2·size、allSm 圆角 |
| 头像优化 | `AppImage.circle` 默认 `cacheWidth=cacheHeight=size`（头像无需大位图） |
| 兜底 | 默认构造不设 cache → memCacheWidth 为 null（按原图解码，行为不变） |

## 3. 快速上手（Quick Start）

```dart
AppImage.thumbnail(item.cover, size: 96);                 // 列表缩略图（小内存）
AppImage(item.cover, cacheWidth: 360);                    // 原图视图：按列宽解码
```

showcase「M21 性能优化体系」→「图片缓存优化」可见 64/96/128px 三档缩略图。

## 5. 与 spec 的偏差与决策

T21.4 决策：在既有 `AppImage`（M14）上**扩展**而非另起组件——保持单一图片入口，向后兼容（默认构造行为不变）。`cacheWidth` 取逻辑像素并在 build 用 `MediaQuery.devicePixelRatio` 换算，避免高 DPR 屏发虚；`thumbnail` 把磁盘缓存原图限制到 2×size，兼顾清晰与体积。
