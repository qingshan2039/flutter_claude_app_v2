## 2. 原生配置摘录

### 2.1 Android

```xml
<!-- 自定义 scheme -->
<intent-filter android:autoVerify="false">
    <action android:name="android.intent.action.VIEW"/>
    <category android:name="android.intent.category.DEFAULT"/>
    <category android:name="android.intent.category.BROWSABLE"/>
    <data android:scheme="fcaapp"/>
</intent-filter>

<!-- App Links（autoVerify=true 需配合 assetlinks.json） -->
<intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW"/>
    <category android:name="android.intent.category.DEFAULT"/>
    <category android:name="android.intent.category.BROWSABLE"/>
    <data android:scheme="https" android:host="app.example.com"/>
</intent-filter>
```

### 2.2 iOS

```xml
<key>FlutterDeepLinkingEnabled</key>
<true/>

<key>CFBundleURLTypes</key>
<array>
    <dict>
        <key>CFBundleTypeRole</key>
        <string>Editor</string>
        <key>CFBundleURLName</key>
        <string>com.ben.claude_flutter_v2</string>
        <key>CFBundleURLSchemes</key>
        <array>
            <string>fcaapp</string>
        </array>
    </dict>
</array>
```

Universal Links 需要 Xcode 中开启 Associated Domains capability + 服务端部署 `apple-app-site-association`。

## 3. Flutter 端处理（无需代码）

go_router 自动接管：
- 应用启动时的 initial route
- 应用运行中的 `WidgetsBinding.platformDispatcher.onPushRoute` 等回调

业务代码**无需**写任何 deep link 监听。如需在跳转前拦截（如登录检查），用 [authRedirect](file:///Users/ben/ai_project/flutter_claude_app_v2/lib/core/router/auth_redirect.dart) 已完成。
