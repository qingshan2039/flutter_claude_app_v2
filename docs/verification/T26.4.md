# T26.4 PlatformView 示例 — 验证报告

> 任务 T26.4 / 模块 M26 原生互操作 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T26.4 实现 `NativePlatformView`：按平台选 `AndroidView` / `UiKitView` 嵌入原生视图，非移动端回退 `fallback`（或默认占位）；静态 `isSupportedOn(platform)` 判定。4 个测试全绿（支持判定 + fallback 渲染，不在测试中实例化真实平台视图）。

## 1. 任务目标（来自 spec）

T26.4（spec 1007-1009）：嵌入原生视图，交付物 PlatformView 示例。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| Android | `AndroidView(viewType, creationParams, StandardMessageCodec)` |
| iOS | `UiKitView(...)` |
| 其它平台 | `fallback ?? _UnsupportedNativeView`（占位文案） |
| 支持判定 | `static isSupportedOn(TargetPlatform)`（android/iOS=true） |
| 原生注册 | 需原生 `registerViewFactory`/`FlutterPlatformViewFactory`（文档说明） |

## 3. 快速上手（Quick Start）

```dart
NativePlatformView(
  viewType: 'my_native_map',
  creationParams: {'zoom': 12},
  fallback: const Text('该平台不支持'),
);
```

## 5. 与 spec 的偏差与决策

T26.4 决策：把平台判定抽成纯静态 `isSupportedOn` 便于单测；测试只验证**判定 + fallback 分支**，不在 widget 测试里实例化真实 `AndroidView`/`UiKitView`（需平台通道、易 flaky）。demo 页用**按需加载**（点按钮才渲染）避免画廊回归测试构建真实平台视图。注：测试中 `debugDefaultTargetPlatformOverride` 必须在测试体内复位（否则框架不变量检查报错——本次已据此修正）。
