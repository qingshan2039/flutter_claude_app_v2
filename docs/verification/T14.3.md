# T14.3 图片组件 — 验证报告

> 任务 T14.3 / 模块 M14 通用 UI 组件 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T14.3 在 `lib/shared/widgets/app_image.dart` 封装 `cached_network_image`：`AppImage`（占位图/错误图/圆角）+ `AppImage.circle`（圆形头像）+ `RoundedClipX.rounded()` 扩展。新增依赖 `cached_network_image: ^3.4.1`。`flutter analyze` 零问题，单测全绿。

## 1. 任务目标（来自 spec）

T14.3 要求封装 cached_network_image，提供占位图/错误图与圆角扩展，交付物 `shared/widgets/app_image.dart`（spec 593-598 行）。

## 2. 实际配置

| spec 期望 | 实际实现 |
|---|---|
| 封装 cached_network_image | `AppImage(url, width, height, fit, borderRadius, placeholder, errorWidget)` |
| 占位图 / 错误图 | 默认中性灰底块 / `broken_image` 图标；均可自定义 |
| 圆角扩展 | `borderRadius` 参数自动套 `ClipRRect`；`AppImage.circle` 圆形；`Widget.rounded()` 扩展 |

## 3. 快速上手（Quick Start）

```dart
AppImage('https://x/a.png', width: 80, height: 80, borderRadius: RadiusTokens.allMd);
AppImage.circle('https://x/avatar.png', size: 48);
anyWidget.rounded(RadiusTokens.allLg); // 任意 Widget 加圆角
```

## 5. 与 spec 的偏差与决策

T14.3 无偏差。决策：默认占位图用静态色块（而非动画 shimmer），避免在 widget 测试里产生永不停止的动画；需要 shimmer 占位时可传 `placeholder: SkeletonBox(...)`。
