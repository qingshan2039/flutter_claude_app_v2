# T23.5 国内 Android 下载更新 — 验证报告

> 任务 T23.5 / 模块 M23 应用内更新 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T23.5 实现 `ApkUpdater`（抽象 + `@LazySingleton` impl）：`downloadApk` 用 Dio 流式下载，支持**断点续传**（按本地已下载字节发 `Range: bytes=N-` 头、`FileMode.append` 追加写）；`installApk` 经 MethodChannel `flutter_claude_app/apk_installer` 触发系统安装器，未接入/非 Android 优雅降级。纯函数 `rangeHeaderFor`/`fileNameFromUrl` + 安装接缝降级有单测。

## 1. 任务目标（来自 spec）

T23.5（spec 924-927）：APK 下载 + 安装引导 + 断点续传，交付物 APK 更新实现。

## 2. 实际配置

| 能力 | 实现 |
|---|---|
| 下载 | `_dio.get<ResponseBody>` 流式，写入 `getTemporaryDirectory()` 下文件 |
| 断点续传 | 本地已存在部分文件 → `Range: bytes=$existing-` + `FileMode.append`；服务端需支持 206 |
| 进度 | `ApkProgressCallback(received, total)` |
| 安装 | `installApk` → channel `install`（Android 需 REQUEST_INSTALL_PACKAGES + FileProvider） |
| 降级 | 安装接缝对 `MissingPluginException`/`PlatformException` → false |
| 纯函数 | `rangeHeaderFor(int)`、`fileNameFromUrl(url)`（去 query、缺省回退 update.apk） |

## 3. 快速上手（Quick Start）

```dart
final apk = getIt<ApkUpdater>();
final path = await apk.downloadApk(info.apkUrl!, onProgress: (r, t) => setProgress(r / t));
await apk.installApk(path);   // 触发系统安装器
```

## 5. 与 spec 的偏差与决策

T23.5 决策：断点续传用「读本地已下载字节 → Range 头 → 追加写」的**真实流式实现**（非 dio.download 覆盖式），并把可单测的 `rangeHeaderFor`/`fileNameFromUrl` 抽成静态纯函数；下载用**独立 Dio**（不带 App 鉴权/baseUrl 拦截器）；安装为平台能力，用 channel 接缝（真机需 FileProvider + 安装权限），host/测试优雅降级。完整网络/安装链路需真机验证。
