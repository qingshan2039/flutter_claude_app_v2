# T28.2 Feature Flag — 验证报告

> 任务 T28.2 / 模块 M28 远程配置与 Feature Flag / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T28.2 实现 `FeatureFlags`（@lazySingleton，基于 RemoteConfig）：`isEnabled(flag)` 读布尔开关；`isEnabledForUser(flag, userId)` 读 `<flag>.rollout`（0–100）按 **FNV-1a 稳定分桶**做灰度，同一用户结果恒定、跨平台一致。纯函数 `RolloutEvaluator` 单测含大样本分布校验。6 个单测全绿。

## 1. 任务目标（来自 spec）

T28.2（spec 1044-1047）：功能开关管理 + 灰度规则，交付物 Feature Flag 模块。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 开关 | `isEnabled(flag, {defaultValue})` → RemoteConfig.getBool |
| 灰度 | `isEnabledForUser(flag, userId)`：读 `<flag>.rollout` % + 稳定分桶 |
| 分桶算法 | `RolloutEvaluator`：FNV-1a 哈希 `flag:userId` → 0–99 桶；`bucket < percent` 命中 |
| 稳定性 | 同 userId+flag 恒定；跨运行/平台一致（不依赖 String.hashCode） |
| 边界 | percent≤0 全否、≥100 全是 |

## 3. 快速上手（Quick Start）

```dart
if (getIt<FeatureFlags>().isEnabled('new_ui')) { ... }
if (getIt<FeatureFlags>().isEnabledForUser('home_banner', userId)) { ... } // 灰度
```

## 5. 与 spec 的偏差与决策

T28.2 决策：灰度用 **FNV-1a** 自实现哈希（保证跨平台/跨运行稳定的分桶，Dart `String.hashCode` 不保证此性质）；灰度百分比存 `<flag>.rollout` 走 RemoteConfig，运营可远程调灰度比例；`RolloutEvaluator` 为纯函数便于充分单测。
