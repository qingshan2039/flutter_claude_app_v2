# T26.2 EventChannel 封装 — 验证报告

> 任务 T26.2 / 模块 M26 原生互操作 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T26.2 实现 `BatteryMonitor`（@LazySingleton）：把原生 EventChannel 持续推送的事件封装成类型安全的 `Stream<int>`（电量示例），`MissingPluginException` 静默降级（未接入时流不发值、不崩溃）。用 `MockStreamHandler` 注入事件验证。2 个测试全绿。

## 1. 任务目标（来自 spec）

T26.2（spec 998-1000）：原生事件流（电量、网络变化）示例，交付物 EventChannel 示例。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 接口 | `BatteryMonitor.levelStream → Stream<int>` |
| 实现 | `EventChannel('flutter_claude_app/battery_stream').receiveBroadcastStream()` → map int |
| 降级 | `handleError(test: MissingPluginException)` 吞掉未实现异常 |
| 网络变化 | 同模式可封装（M25 `ConnectivityService` 即网络状态流的等价物） |

## 3. 快速上手（Quick Start）

```dart
StreamBuilder<int>(
  stream: getIt<BatteryMonitor>().levelStream,
  builder: (_, snap) => Text(snap.hasData ? '${snap.data}%' : '…'),
);
```

## 5. 与 spec 的偏差与决策

T26.2 决策：以电量流为 EventChannel 示例（网络变化已由 M25 `ConnectivityService` 体现，避免重复）；`handleError` 仅吞 `MissingPluginException`，其它错误照常透出；测试用框架自带 `MockStreamHandler` 而非真实原生，保证 CI 可跑。原生侧需在 `onListen` 持续 `sink.success(level)`。
