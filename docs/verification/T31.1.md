# T31.1 用户分桶 — 验证报告

> 任务 T31.1 / 模块 M31 灰度发布与 A/B Test / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T31.1 实现 `Bucketer`（纯静态）：`bucketOf(unitId, salt, buckets)` 用 **FNV-1a** 把 userId/设备 ID 稳定哈希到 `[0, buckets)`；`resolveUnitId(userId/deviceId)` 优先登录态、回退设备/匿名；`isInRollout(percent)` 百分比灰度。跨平台/跨运行稳定（不依赖 `String.hashCode`）。5 个单测覆盖（稳定性/范围/salt 独立/分布≈均匀）。

## 1. 任务目标（来自 spec）

T31.1（spec 1116-1120）：UserID / 设备 ID hash + 分桶工具，交付物分桶模块。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 分桶 | `bucketOf(unitId, {salt, buckets=100})` FNV-1a → 稳定桶 |
| 单位解析 | `resolveUnitId(userId/deviceId)`：userId > deviceId > anonymous |
| 灰度 | `isInRollout(unitId, percent, salt)` |
| 稳定性 | 同 unitId+salt 恒定；salt 区分不同实验避免相关性 |

## 3. 快速上手（Quick Start）

```dart
final unit = Bucketer.resolveUnitId(userId: user?.id, deviceId: deviceId);
final bucket = Bucketer.bucketOf(unit, salt: 'button_color'); // 0–99
if (Bucketer.isInRollout(unit, percent: 30, salt: 'new_feature')) { /* 灰度命中 */ }
```

T31.1 决策：分桶用 FNV-1a 自实现（跨平台稳定，与 M28 `RolloutEvaluator` 同思路；本模块作为通用「分桶工具」）；分桶单位解析内置「登录优先、设备/匿名兜底」策略，便于直接对接业务。
