# T26.3 Pigeon 集成 — 验证报告

> 任务 T26.3 / 模块 M26 原生互操作 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T26.3 引入 `pigeon` 26.3.4（dev_dependency）+ schema `pigeons/native_messages.dart`（`DeviceDetails` DTO + `@HostApi NativeDeviceApi` + `@FlutterApi NativeEventApi`），运行 `dart run pigeon` 生成类型安全通信代码 `lib/core/native/pigeon/native_messages.g.dart`（默认 Dart-only，不碰原生工程）。生成 API 编译 + 可实例化，2 个测试全绿。

## 1. 任务目标（来自 spec）

T26.3（spec 1002-1005）：类型安全通信 + 代码生成，交付物 Pigeon 示例。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| schema | `pigeons/native_messages.dart`：`@ConfigurePigeon` + `DeviceDetails` + `@HostApi`(getDeviceDetails/greet) + `@FlutterApi`(onNativeTick) |
| 生成命令 | `dart run pigeon --input pigeons/native_messages.dart` |
| 生成产物 | `lib/core/native/pigeon/native_messages.g.dart`（类型安全 BasicMessageChannel，无需手写序列化） |
| 原生输出 | 默认仅 Dart（schema 内 kotlinOut/swiftOut 注释，取消即生成原生接口供实现） |
| 依赖 | `pigeon: ^26.3.4`（dev，仅 codegen，无运行时依赖） |

## 5. 与 spec 的偏差与决策

T26.3 决策：真实引入 pigeon 并生成（满足「代码生成」），但**默认只生成 Dart**（注释掉 kotlinOut/swiftOut），避免向原生工程写入需配套实现的文件而破坏 CI；schema 注释说明取消注释即可生成 Kotlin/Swift 接口。pigeon 为 dev 依赖（codegen-only），`flutter pub add` 解析无冲突。
