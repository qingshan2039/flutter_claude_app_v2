# T14.1 状态组件集 — 验证报告

> 任务 T14.1 / 模块 M14 通用 UI 组件 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T14.1 在 `lib/shared/widgets/states/` 下实现了一组页面状态组件：`LoadingWidget`（局部/全屏）+ `SkeletonBox`/`SkeletonLoader`（骨架屏）、`EmptyWidget`、`AppErrorView`、`NetworkErrorWidget`，并提供 `FailureView` 把 M03 的 `Failure` 直接映射到对应组件。`flutter analyze` 零问题，`test/shared/widgets/states_test.dart` 全绿。

## 1. 任务目标（来自 spec）

T14.1 要求交付状态组件集（spec `flutter_template_v3.md` 582-588 行）：LoadingWidget（全屏 / 局部 / 骨架屏）、EmptyWidget、ErrorWidget、NetworkErrorWidget，交付物目录 `shared/widgets/states/`。

## 2. 实际配置

| spec 期望 | 实际实现 | 偏差原因 |
|---|---|---|
| LoadingWidget（全屏/局部/骨架屏） | `LoadingWidget` + `LoadingWidget.fullscreen` + `SkeletonBox`/`SkeletonLoader` | 骨架屏拆为 `SkeletonBox`（单元）+ `SkeletonLoader`（列表），shimmer 用 `AnimationController` 自绘，零额外依赖 |
| ErrorWidget | `AppErrorView` | 重命名避免与 Flutter 自带 `ErrorWidget`（红屏）冲突 |
| NetworkErrorWidget | `NetworkErrorWidget` + `FailureView` | 额外加 `FailureView`：按 M03 `Failure` 子类型分派到对应状态组件 |

## 3. 快速上手（Quick Start）

```dart
import 'package:flutter_claude_app_v2/shared/widgets/states/states.dart';

const LoadingWidget(message: '加载中…');          // 局部转圈
const LoadingWidget.fullscreen();                 // 整页转圈
const SkeletonLoader(itemCount: 6);               // 列表骨架屏
EmptyWidget(title: '暂无数据', actionLabel: '去添加', onAction: ...);
AppErrorView(message: '请求失败', onRetry: reload);
NetworkErrorWidget(onRetry: reload);
FailureView(failure: someFailure, onRetry: reload); // 按 Failure 分派
```

## 5. 与 spec 的偏差与决策

T14.1 偏差：(1) `ErrorWidget` 改名 `AppErrorView`，因 Flutter 框架已占用 `ErrorWidget`。(2) 新增 `FailureView`，把 M03 `Failure` sealed class 用 switch 穷尽映射到状态组件，使「Repository 返回 Failure → 直接渲染」成为一行代码。(3) 骨架屏自绘 shimmer（`LinearGradient` + `AnimationController`），不引入 `shimmer` 包，减少依赖。
