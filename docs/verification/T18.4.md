# T18.4 防截屏 — 验证报告

> 任务 T18.4 / 模块 M18 安全规范 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T18.4 实现 `ScreenSecurity`（seam + MethodChannel impl，@lazySingleton）+ `SecureScreen` 组件（进页 enable、离页 disable）；Android 原生 `MainActivity.kt` 用 `FLAG_SECURE` 实现。iOS 静默降级（系统无等价 API，文档说明）。

## 1. 任务目标（来自 spec）

T18.4（spec 744-747，可选）：敏感页面禁用截屏，交付物防截屏工具。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 接口 | `ScreenSecurity { enableSecure(); disableSecure(); }` |
| 实现 | `ScreenSecurityImpl`（MethodChannel `flutter_claude_app/screen_security`，MissingPlugin 优雅降级） |
| 组件 | `SecureScreen(child)`：initState→enable、dispose→disable |
| 原生 | Android `MainActivity.kt` FLAG_SECURE add/clear |
| iOS | 无 FLAG_SECURE；需原生模糊层，本类静默降级（文档说明） |

## 3. 快速上手（Quick Start）

```dart
SecureScreen(child: PaymentPage());          // 推荐
getIt<ScreenSecurity>().enableSecure();      // 手动
```

## 5. 与 spec 的偏差与决策

T18.4 决策：用 MethodChannel + 原生 FLAG_SECURE（不引第三方包）。Dart 侧 `MissingPluginException` 优雅降级，使 iOS/桌面/测试不报错。iOS 真防截屏需原生模糊层（成本高、可选），本模板文档化而非内置。
