# T15.1 定义环境模型 — 验证报告

> 任务 T15.1 / 模块 M15 多环境配置 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T15.1 在 `lib/core/env/env_config.dart` 定义不可变 `EnvConfig` 数据类（基于 M13 已有的 `AppEnvironment` 枚举）：`defaults(env)` 给三套环境非敏感默认值（纯函数），`resolve(env)` 叠加 dart-define 覆盖；通过 `envConfigProvider`（Riverpod）+ `registerEnvConfig`（getIt）注册。10 个单测全绿，analyze 零问题。

## 1. 任务目标（来自 spec）

T15.1 要求定义环境模型（spec 582-588 行）：Environment 枚举（dev/staging/prod）+ EnvConfig 数据类，交付物 `core/env/env_config.dart`。

## 2. 实际配置

| spec 期望 | 实际实现 |
|---|---|
| Environment 枚举 | 复用 M13 的 `AppEnvironment{dev,staging,prod}`（已含 injectableName/isReleaseLike） |
| EnvConfig 数据类 | `EnvConfig`：environment/appName/appId/apiBaseUrl/enableLogging/enableCrashReporting/sentryDsn + copyWith/==/hashCode/toString(脱敏) |
| 注册 | `envConfigProvider`（默认 dev，入口 override）+ `registerEnvConfig(env)`（getIt 单例） |

## 3. 快速上手（Quick Start）

```dart
final env = ref.watch(envConfigProvider);  // UI 层
final env = getIt<EnvConfig>();             // 非 widget 层
EnvConfig.defaults(AppEnvironment.prod);    // 纯默认值
EnvConfig.resolve(AppEnvironment.prod);     // 叠加 dart-define
```

测试覆盖：三环境 defaults（包名后缀/日志/上报）、resolve 无 define 时等于 defaults、copyWith、==/hashCode、hasSentryDsn、toString 脱敏、provider 默认 dev + override。

## 5. 与 spec 的偏差与决策

T15.1 决策：(1) 不新建 Environment 枚举，复用 M13 的 `AppEnvironment`（避免双枚举）。(2) `EnvConfig` 拆 `defaults`（纯/可测）与 `resolve`（读 dart-define）两段，便于单测且让 dart-define 注入点单一。(3) `toString` 对 `sentryDsn` 脱敏，防日志泄露。
