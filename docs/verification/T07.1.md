## 2. 设计要点

### 2.1 工厂函数而非 @lazySingleton GoRouter

`GoRouter` 需要 `ProviderContainer`（guard 用）+ `RouterLogObserver`（监听用）。直接 `@module` 注入 ProviderContainer 会引发循环依赖（Provider 树尚未建好）。改用：

```dart
GoRouter createAppRouter({
  required ProviderContainer container,
  required RouterLogObserver observer,
}) { ... }
```

由 M13/T13.1 在 bootstrap 中调用：拿到 container 与 observer 后构造 router 传给 `MaterialApp.router`。

### 2.2 路由 name + path 分离

`RouteNames` 类导出语义 name（`home`、`detail` 等）用于 `context.goNamed(...)`；`RoutePaths` 导出 path 字符串供测试 / URL 构造。生产代码用 name，避免拼写错误。

### 2.3 路由结构

```
ROOT
├── Shell (StatefulShellRoute.indexedStack)
│   ├── / (HomePage)         ← branch 0
│   ├── /search (SearchPage) ← branch 1
│   └── /settings (SettingsPage) ← branch 2
├── /detail/:id (DetailPage, fade)
├── /login (LoginPage, slide-up)
└── /typed-detail/:id (DetailPage, 类型安全示例)
errorBuilder → NotFoundPage
redirect → authRedirect
```
