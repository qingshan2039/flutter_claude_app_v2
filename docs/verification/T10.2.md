## 2. 设计要点

### 2.1 ColorScheme.fromSeed

```dart
final colorScheme = ColorScheme.fromSeed(
  seedColor: ColorTokens.brandSeed,
  brightness: brightness,
);
```

单一品牌种子色派生整套 M3 调色板（primary/secondary/tertiary/surface/error 等角色 + 各自 on- 色 + container 变体）。换品牌色只改一个常量。

### 2.2 Token 驱动的组件主题

`_build(brightness)` 用 T10.1 token 装配各组件：
- AppBar：surface 背景 + 0 elevation + scrolledUnderElevation 2
- Card：surfaceContainerLow + `RadiusTokens.allLg` + token margin
- FilledButton / OutlinedButton：48 高 + `RadiusTokens.allMd`
- InputDecoration：填充 + `RadiusTokens.allMd` 无边框
- Dialog / BottomSheet：`RadiusTokens.allLg` / `topLg`

### 2.3 注入业务色 extension

```dart
extensions: [isDark ? AppColorsExtension.dark : AppColorsExtension.light]
```
