## 2. 设计要点

### 2.1 isLoggedInProvider 默认 false

```dart
final isLoggedInProvider = StateProvider<bool>(
  (ref) => false,
  name: 'isLoggedInProvider',
);
```

模板首版默认未登录，访问 `/` 即被守卫弹回 `/login`，演示直观。M19/T19.1 完成后：
1. 登录成功 → `ref.read(isLoggedInProvider.notifier).state = true`
2. 登出 / token 失效 → `ref.read(...).state = false`，守卫自动接管

### 2.2 公开路径白名单

```dart
const _publicPaths = <String>{'/login'};
```

未登录用户可访问的页面。后续如需「忘记密码」等公开页，追加路径。

### 2.3 redirect 注入

```dart
GoRouter(
  redirect: (context, state) => authRedirect(container, state),
);
```

`ProviderContainer` 由 main.dart 在 `ProviderScope` 之外手工持有引用（M13/T13.1 编排）；当前 `createAppRouter` 接收 container 参数显式注入。

### 2.4 「权限拦截」尚未实现

spec 提到「权限拦截」（除登录外的角色 / 功能 flag）。本任务未实现复杂权限模型，原因：
- M28（Feature Flag / RemoteConfig）会落地权限来源
- 现阶段所有内部页面只需登录态即可

后续：在 [authRedirect] 中加入 role 检查或调用 `featureFlag(path)` 判定。
