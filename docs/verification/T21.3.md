# T21.3 列表性能优化 — 验证报告

> 任务 T21.3 / 模块 M21 性能优化体系 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T21.3 实现 `HighPerformanceListPage`（万级长列表）：`ListView.builder` 按需构建 + **`itemExtent` 固定行高**（跳过逐项布局、滚动定位 O(1)）+ 每行 **`RepaintBoundary`** 隔离 + 行内容尽量 const。接入 showcase「M21 性能优化体系」可一键打开 1 万项列表体验。3 个 widget 测试全绿。

## 1. 任务目标（来自 spec）

T21.3（spec 853-856）：长列表分页示例 + itemExtent 优化，交付物高性能列表示例。

## 2. 实际配置

| 优化 | 实现 |
|---|---|
| 按需构建 | `ListView.builder(itemCount: 10000)` |
| 固定行高 | `itemExtent: 72`（`useItemExtent=false` 可对照不定高） |
| 图层隔离 | `itemBuilder` → `RepaintBoundary(child: _FixedHeightRow(...))` |
| const 行 | `_FixedHeightRow` 除 index 外尽量 const |
| 分页 | 文档指向 M14 `AppRefreshList`（首页 `features/home` 已用：下拉刷新 + 上拉分页） |

## 5. 与 spec 的偏差与决策

T21.3 决策：分页能力不重复造轮子——长列表本体演示 itemExtent/RepaintBoundary，分页复用 M14 `AppRefreshList`（已在首页落地）。`itemExtent` 是长列表收益最大的优化，故作为默认开启并提供对照开关。注：本 Flutter 版本 `ListView` 的 `cacheExtent` 已被新 `scrollCacheExtent`（`ScrollCacheExtent` 类型）取代，示例不设该可选项以保持简洁与跨版本稳定。
