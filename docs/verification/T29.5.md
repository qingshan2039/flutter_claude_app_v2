# T29.5 缓存清理 — 验证报告

> 任务 T29.5 / 模块 M29 内置 Debug 面板 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T29.5 实现 `CacheCleaner`（@lazySingleton）：`clearKeyValue`（SharedPreferences）/ `clearSecure`（安全存储）/ `clearImageCache`（PaintingBinding imageCache + live）/ `clearAll` 一键清理。Debug 面板「缓存」Tab 四个按钮逐项/一键清理。4 个单测全绿。

## 1. 任务目标（来自 spec）

T29.5（spec 1083-1085）：一键清理各类缓存，交付物缓存清理工具。

## 2. 实际配置

| 方法 | 清理对象 |
|---|---|
| `clearKeyValue()` | KeyValueStorage（SharedPreferences） |
| `clearSecure()` | SecureStorage（token 等） |
| `clearImageCache()` | `imageCache.clear()` + `clearLiveImages()` |
| `clearAll()` | 以上全部 |

## 3. 快速上手（Quick Start）

```dart
await getIt<CacheCleaner>().clearAll(); // 退出登录/清缓存设置项也可复用
```

## 5. 与 spec 的偏差与决策

T29.5 决策：复用现有 KeyValueStorage/SecureStorage + PaintingBinding imageCache（零新依赖）；提供细粒度方法 + clearAll，既供 Debug 面板也可被「设置-清除缓存」复用；与 M24 `UserDataEraser`（注销清数据）职责区分——CacheCleaner 偏「缓存」，可含图片缓存。
