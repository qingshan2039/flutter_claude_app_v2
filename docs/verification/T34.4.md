# T34.4 Lottie 集成 — 验证报告

> 任务 T34.4 / 模块 M34 动效系统 / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T34.4 交付 `LottieView`——**零依赖 seam**（经用户确认）：默认渲染一个可控占位动画（`AnimationController` 驱动旋转，支持 `autoplay`/`repeat`/`size`/`source`），暴露与真实 Lottie 一致的 API；不引入 `lottie` 依赖、不绑定二进制资源。文档注明两步接入真实 lottie（加依赖 + 替换 `build` 占位），业务调用处零改动。2 个单测全绿。

## 1. 任务目标（来自 spec）

T34.4（spec 1187-1189）：加载与播放工具，交付物 Lottie 组件。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 组件 | `LottieView{required source, sourceType=asset, size=120, autoplay=true, repeat=true, semanticLabel?}` |
| 播放控制 | `AnimationController`（vsync）：`autoplay` 决定是否播；`repeat` 决定循环 vs 单次 |
| 响应变更 | `didUpdateWidget` 在 autoplay/repeat 变化时重应用播放状态 |
| 无障碍 | `Semantics(label: semanticLabel ?? 'Lottie 动画占位：$source')` |
| 接入真实 lottie | 文档：`flutter pub add lottie` + 把 build 占位换为 `Lottie.asset(source, repeat:, animate:)` |

## 3. 快速上手（Quick Start）

```dart
LottieView(source: 'assets/lottie/loading.json', repeat: true);
// 接真实：pubspec 加 lottie: ^3.1.0，build 内换成 Lottie.asset(widget.source, ...)
```

## 5. 与 spec 的偏差与决策

T34.4 决策（**用户选择「零依赖 seam」**）：spec 点名 Lottie，但本模板坚持「零新增依赖优先」，且用户在 M30/M33 已主动裁剪 P2 范围。故 `LottieView` 与 M18/M23/M26 平台能力一致采用「抽象 + 优雅降级 + 文档化真实接入」的 seam：默认占位是**可控动画**（演示 autoplay/repeat 的「加载与播放」语义），既零依赖零资源、单测稳定，又保留与真实 `lottie`（纯 Dart 包）一致的 API，按需两步切换。回归守卫中 M34 页因占位无限循环改用有界 pump（同 M14）。
