## 2. 设计要点

### 2.1 NotFoundPage 构造接受错误上下文

```dart
class NotFoundPage extends StatelessWidget {
  const NotFoundPage({super.key, this.error, this.path});
  final Exception? error;
  final String? path;
  ...
}
```

- `path` 用于 UI 文案（"We couldn't find: $path"）
- `error` 用于将来上报（M11 / Sentry），UI 暂不展示
- 两者均可空 — 直接 push NotFoundPage 时无参数也能用

### 2.2 errorBuilder 接入

```dart
GoRouter(
  errorBuilder: (context, state) => NotFoundPage(
    error: state.error,
    path: state.uri.toString(),
  ),
);
```
