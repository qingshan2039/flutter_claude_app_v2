## 2. 设计要点

### 2.1 监听 4 种导航事件

```dart
@override void didPush(...)     // '[Route] push /xx (from /yy)'
@override void didPop(...)      // '[Route] pop  /xx (to /yy)'
@override void didReplace(...)  // '[Route] replace /xx → /yy'
@override void didRemove(...)   // '[Route] remove /xx'
```

`route.settings.name` 优先，否则用 `runtimeType.toString()`，与 [route_names.dart] 的命名联动。

### 2.2 testing hook：recordSink

```dart
@visibleForTesting
List<String>? recordSink;
```

测试可：

```dart
final observer = RouterLogObserver()..enabled = true;
observer.recordSink = <String>[];
// 触发事件后断言 recordSink 内容
```

生产期不设此字段，零开销。

### 2.3 enabled 字段而非构造参数

同 T06.3 AppProviderObserver 修复模式 — 避免 injectable 找不到 `bool` 注册。

### 2.4 接入路由表

```dart
GoRouter(
  observers: <NavigatorObserver>[observer],
  ...
);
```

由 [createAppRouter] 显式接收 observer 参数。M13/T13.1 在 bootstrap 中 `getIt<RouterLogObserver>()` 注入。
