## 2. 设计要点

### 2.1 5 级门面

`AppLogger`：`t`(trace/verbose) / `d`(debug) / `i`(info) / `w`(warning) / `e`(error)，每个接受 `{Object? error, StackTrace? stackTrace}`。业务只依赖抽象，不 import logger 包。

### 2.2 dev/prod 策略

```dart
Logger(level: kReleaseMode ? Level.warning : Level.trace, ...)
```

- debug 构建：全量输出（trace 及以上），PrettyPrinter 带颜色/emoji
- release 构建：只 warning+，无颜色（减少噪声、不泄露细节）

### 2.3 脱敏接入（T11.3）

每条消息 `_sanitizer.sanitize(message)` 后才交给底层 logger，token/password 等不落日志。

### 2.4 可测构造

```dart
@visibleForTesting
LoggerImpl.withLogger(this._logger, {LogSanitizer? sanitizer});
```

injectable 用默认无参构造；测试用 `withLogger` 注入带 `MemoryOutput` 的 Logger 以断言输出。
