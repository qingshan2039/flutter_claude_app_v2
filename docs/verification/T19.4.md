# T19.4 设置页模块 — 验证报告

> 任务 T19.4 / 模块 M19 示例业务模块 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T19.4 在 `features/settings/` 落地设置页（Shell 第三个 Tab）：语言用 `SegmentedButton<String>`（system/en/zh → `localeProvider.notifier.setLocale`）、主题用 `SegmentedButton<ThemeMode>`（系统/亮/暗 → `themeModeProvider.notifier.setThemeMode`）——均复用 M08/M10 自动持久化 provider；退出登录与账户注销调 `AuthRepository.signOut()` + 置 `isLoggedInProvider=false` + `goNamed(login)`，注销前用 M14 `OverlayService.showConfirm(destructive)` 二次确认。验收：analyze 0 issue、test 全绿、dev APK 构建成功。

## 1. 任务目标（来自 spec）

T19.4（spec 780-785）：设置页模块需覆盖**语言切换、主题切换、退出登录、账户注销入口**，交付物 `features/settings/`。

## 2. 实际配置

| 关注点 | 实现 |
|---|---|
| 语言切换 | `SegmentedButton<String>` 选段 system/en/zh，`ref.read(localeProvider.notifier).setLocale(v=='system'?null:Locale(v))`（复用 M08，自动持久化） |
| 主题切换 | `SegmentedButton<ThemeMode>` 选段 system/light/dark，`ref.read(themeModeProvider.notifier).setThemeMode(...)`（复用 M10，自动持久化） |
| 退出登录 | `_signOut`：`getIt<AuthRepository>().signOut()` → `isLoggedInProvider=false` → `context.goNamed(RouteNames.login)` |
| 账户注销入口 | `_deleteAccount`：`OverlayService.showConfirm(destructive:true)` 确认 → signOut → `showSuccess('账户已注销')` → 跳登录（error 配色 ListTile） |
| 权限演示入口 | ListTile → `context.goNamed(RouteNames.permissions)`（衔接 T19.5） |
