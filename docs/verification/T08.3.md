## TL;DR

T08.3 在 ARB 中演示 4 类复杂国际化：占位符（`greetingNamed`）、复数（`itemCount` / `unreadMessages`）、日期格式化（`lastUpdated`，DateFormat yMMMd）、数字格式化（`priceLabel` 货币 $、`completionRate` 百分比）。gen-l10n 把它们生成为带参数的方法。6 条测试验证各种格式化输出。

## 2. 4 类复杂场景

### 2.1 占位符 placeholder

```json
"greetingNamed": "Hello, {name}!",
"@greetingNamed": {
  "placeholders": { "name": { "type": "String", "example": "Alice" } }
}
```

生成 → `String greetingNamed(String name)`。调用 `l10n.greetingNamed('Alice')` → `Hello, Alice!`。

### 2.2 复数 plural

```json
"itemCount": "{count, plural, =0{No items} =1{1 item} other{{count} items}}",
"@itemCount": {
  "placeholders": { "count": { "type": "int" } }
}
```

生成 → `String itemCount(int count)`。`itemCount(0)`→`No items`，`itemCount(1)`→`1 item`，`itemCount(5)`→`5 items`。

中文只有 `other` 类别：`{count, plural, =0{没有条目} other{{count} 个条目}}`。

### 2.3 日期格式化

```json
"lastUpdated": "Last updated: {date}",
"@lastUpdated": {
  "placeholders": { "date": { "type": "DateTime", "format": "yMMMd" } }
}
```

生成 → `String lastUpdated(DateTime date)`，内部用 `intl` 的 `DateFormat.yMMMd(locale)` 按 locale 格式化。

### 2.4 数字格式化

```json
"priceLabel": { "amount": { "type": "double", "format": "currency",
  "optionalParameters": { "symbol": "$", "decimalDigits": 2 } } }
"completionRate": { "value": { "type": "double", "format": "percentPattern" } }
```

`priceLabel(19.99)` → `Price: $19.99`；`completionRate(0.87)` → `Completion: 87%`。
