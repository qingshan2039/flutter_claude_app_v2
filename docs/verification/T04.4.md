## 3. 设计要点

### 3.1 onResponse 业务码检查

```dart
if (data is Map && data.containsKey('code')) {
  final code = data['code'];
  if (code is int && code != ApiResponse.kSuccessCode) {
    handler.reject(DioException(
      requestOptions: response.requestOptions,
      response: response,
      type: DioExceptionType.badResponse,
      error: ServerException(code: code.toString(), message: ..., statusCode: ...),
    ), true);
    return;
  }
}
```

`handler.reject(error, true)` 让后续 error interceptors 也运行，便于其它拦截器（如未来的 sentry 上报）介入。

### 3.2 onError 透传保护

```dart
if (err.error is AppException) return handler.next(err);   // 前置已转换，不重复包装
```

因为 RetryInterceptor 与 AuthInterceptor 都在 onError 中重发请求，可能让 DioException 多次经过本拦截器。如果 `err.error` 已是 AppException，直接透传不再覆盖。

### 3.3 `const` 构造 + DI

```dart
@lazySingleton
class ApiErrorInterceptor extends Interceptor {
  const ApiErrorInterceptor();
  ...
}
```

无状态，可 `const`。injectable 会生成 `gh.lazySingleton<ApiErrorInterceptor>(() => const ApiErrorInterceptor())`。
