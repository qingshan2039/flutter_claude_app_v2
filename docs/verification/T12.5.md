## 2. 设计要点

### 2.1 铰链检测

```dart
static DisplayFeature? hinge(MediaQueryData mq) {
  for (final f in mq.displayFeatures) {
    if (f.type == DisplayFeatureType.hinge || f.type == DisplayFeatureType.fold) return f;
  }
  return null;
}
```

`isVerticalHinge`（高 ≥ 宽）判定左右分屏。

### 2.2 HingeAwareTwoPane 避让

- 无铰链：普通 `Row` 双栏（按 flex）
- 垂直铰链：`start` 占铰链左侧（`SizedBox(width: hingeBounds.left)`），中间留 `hingeBounds.width` 空隙，`end` 占右侧 → 内容不压在折痕上

## 3. 实施过程的 Bug 修复

`DisplayFeature` / `DisplayFeatureType` / `DisplayFeatureState` 定义在 `dart:ui`，`package:flutter/widgets.dart` 与 `material.dart` 对它们的 re-export 在本 Flutter 版本不可靠（analyze 报 undefined）。

**修复**：在 [foldable.dart](file:///Users/ben/ai_project/flutter_claude_app_v2/lib/core/responsive/foldable.dart) 与测试中显式 `import 'dart:ui' show DisplayFeature, DisplayFeatureType;`。
