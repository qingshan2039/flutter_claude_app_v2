## 5. 与 spec 的偏差与决策

T17.4 决策：`integration_test` 默认需要**真机/模拟器**——`flutter test integration_test`
在无设备的纯 host 上会卡在「等待设备」。因此：
- 文件用标准 `IntegrationTestWidgetsFlutterBinding`，在 CI 的模拟器 job / 本地设备上跑。
- 其端到端逻辑已用「等价 host widget pump」（普通 `flutter test` 绑定）验证通过。
- CI 基础流水线**不**自动跑 integration_test（避免卡死），应放到带 Android 模拟器的
  独立 job（`reactivecircus/android-emulator-runner`）。
