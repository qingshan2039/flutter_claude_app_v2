## 3. 设计要点

### 3.1 类签名

```dart
@lazySingleton
class ErrorMapper {
  const ErrorMapper();

  Failure map(Object error) {
    return switch (error) {
      NetworkException(message: final m) => Failure.network(message: m),
      ServerException(message: final m, statusCode: final s, code: final c) =>
        Failure.server(message: m, statusCode: s, code: c),
      // ... 8 more arms
      _ => Failure.unknown(message: error.toString()),
    };
  }
}
```

- **`@lazySingleton`**：注册到 DI，Repository 实现注入使用：`getIt<ErrorMapper>()`
- **`const` 构造**：在 injection.config.dart 中 `const ErrorMapper()` 重用同一字面量
- **Dart 3 switch 表达式 + 模式匹配**：每种 Exception 类型独立分支，编译期类型安全

### 3.2 覆盖矩阵

| 输入 | 输出 Failure |
|---|---|
| `NetworkException` | `NetworkFailure` |
| `ServerException` | `ServerFailure`（保留 `statusCode` + `code`） |
| `CacheException` | `CacheFailure` |
| `UnauthorizedException` | `UnauthorizedFailure` |
| `ValidationException` | `ValidationFailure`（保留 `field`） |
| `UnknownException` | `UnknownFailure` |
| `SocketException` | `NetworkFailure`（empty message → 兜底 'Network unreachable'） |
| `HttpException` | `NetworkFailure` |
| `FormatException` | `ValidationFailure` |
| 其他 `Object` | `UnknownFailure(message: error.toString())` |

第三方 SDK 异常（DioException、PlatformException 等）由各自模块（M04 网络层）在拦截器中预先转为 `AppException` 再传给 mapper，**ErrorMapper 不直接依赖第三方 SDK**——保持核心干净。

## 4. 快速上手

### 4.1 标准 Repository 使用模板

```dart
@LazySingleton(as: AuthRepository)
class AuthRepositoryImpl implements AuthRepository {
  AuthRepositoryImpl(this._remoteDataSource, this._mapper);
  final AuthRemoteDataSource _remoteDataSource;
  final ErrorMapper _mapper;

  @override
  Future<Result<User>> login(LoginInput input) async {
    try {
      final model = await _remoteDataSource.login(input);
      return Success(model.toEntity());
    } on Exception catch (e) {
      return Failed(_mapper.map(e));
    } catch (e) {
      // 兜底，捕获 Error / 非 Exception
      return Failed(_mapper.map(e));
    }
  }
}
```
