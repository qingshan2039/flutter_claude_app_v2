## 2. 设计要点

### 2.1 状态分发

```dart
class AppLifecycleObserver with WidgetsBindingObserver {
  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    _logger?.d('[lifecycle] $state');
    switch (state) {
      case AppLifecycleState.resumed: onResumed?.call();
      case AppLifecycleState.inactive: onInactive?.call();
      case AppLifecycleState.paused: onPaused?.call();
      case AppLifecycleState.detached: onDetached?.call();
      case AppLifecycleState.hidden: onHidden?.call();
    }
  }

  @override
  void didHaveMemoryPressure() {
    _logger?.w('[lifecycle] memory pressure');
    onMemoryPressure?.call();
  }
}
```

所有回调可选（null 安全）；穷尽 switch 覆盖全部 5 个状态。

### 2.2 典型用途

| 钩子 | 用途 |
|---|---|
| onPaused | 保存草稿、暂停视频、停止定位 |
| onResumed | 刷新 token、恢复轮询、检查更新 |
| onMemoryPressure | 清理图片缓存、释放大对象 |

### 2.3 接入（App initState）

```dart
_lifecycleObserver = AppLifecycleObserver(logger: getIt<AppLogger>());
WidgetsBinding.instance.addObserver(_lifecycleObserver);
// dispose: removeObserver
```
