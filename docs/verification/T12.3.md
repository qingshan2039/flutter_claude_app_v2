## 2. 设计要点

### 2.1 用 TextScaler（现代 API）

Flutter 3.16+ 用 `TextScaler` 取代 deprecated `textScaleFactor`。`TextScaler.clamp(minScaleFactor, maxScaleFactor)` 返回钳制后的 scaler：

```dart
static TextScaler clamp(TextScaler scaler, {double min = 0.8, double max = 1.4}) =>
    scaler.clamp(minScaleFactor: min, maxScaleFactor: max);
```

### 2.2 全局接入

```dart
MaterialApp(
  builder: (context, child) => ClampedTextScaling(child: child!),
);
```

系统超大字体（无障碍）会撑破布局；钳制到 1.4 倍上限既尊重用户偏好又保布局完整。
