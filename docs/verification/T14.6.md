# T14.6 BottomSheet 工具 — 验证报告

> 任务 T14.6 / 模块 M14 通用 UI 组件 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T14.6 在 `lib/shared/utils/bottom_sheet_utils.dart` 以 `OverlayService` 扩展（`BottomSheetX`）实现统一样式底部弹层：`showAppBottomSheet`（顶部大圆角 + 拖拽手柄 + 拖拽关闭 + 安全区）与 `showDraggableSheet`（可拖拽高度）。复用 T14.5 的全局 `navigatorKey`，同样脱离 BuildContext。

## 1. 任务目标（来自 spec）

T14.6 要求 BottomSheet 工具：统一样式、支持拖拽关闭（spec 609-613 行）。

## 2. 实际配置

| spec 期望 | 实际实现 |
|---|---|
| 统一样式 | `RoundedRectangleBorder(RadiusTokens.topLg)` 顶部大圆角 + `showDragHandle` 手柄 + `useSafeArea` |
| 支持拖拽关闭 | `enableDrag: true`（默认）；`isDismissible: true` 点蒙层关闭 |
| 脱离 context | 作为 `OverlayService` 扩展，复用 `navigatorKey` |

## 3. 快速上手（Quick Start）

```dart
getIt<OverlayService>().showAppBottomSheet<void>(
  builder: (_) => Column(mainAxisSize: MainAxisSize.min, children: [...]),
);
// 可拖拽高度（长列表/半屏详情）：
getIt<OverlayService>().showDraggableSheet<void>(
  builder: (_, controller) => ListView(controller: controller, children: [...]),
);
```

## 5. 与 spec 的偏差与决策

T14.6 决策：实现为 `OverlayService` 的 **extension** 而非独立类——这样底部弹层与 Toast/Dialog 共用同一套全局 Key（单一真相源），又能按交付物拆到独立文件 `bottom_sheet_utils.dart`。`showDraggableSheet` 关掉默认手柄，改用 `DraggableScrollableSheet` 的拖拽语义。
