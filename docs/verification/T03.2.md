## 3. 设计要点

### 3.1 freezed sealed class 多变体

```dart
@freezed
sealed class Failure with _$Failure {
  const factory Failure.network({@Default('Network error') String message}) = NetworkFailure;
  const factory Failure.server({required String message, int? statusCode, String? code}) = ServerFailure;
  const factory Failure.cache({@Default('Cache error') String message}) = CacheFailure;
  const factory Failure.unauthorized({@Default('Unauthorized') String message}) = UnauthorizedFailure;
  const factory Failure.validation({required String message, String? field}) = ValidationFailure;
  const factory Failure.unknown({@Default('Unknown error') String message}) = UnknownFailure;
}
```

设计要点：
- **`sealed`**：Dart 3 sealed class 让 `switch` 穷尽检查，遗漏变体编译期报错
- **freezed 自动提供**：value equality、`copyWith`、`toString`、hashCode
- **统一字段 `message`**：所有变体都有 message，便于 UI 通用展示
- **变体特有字段**：`ServerFailure.statusCode` + `code`、`ValidationFailure.field`
- **不携带 `stackTrace`**：领域层不关心调试细节；调试信息留在 data 层日志（`AppException.stackTrace`）

## 4. 快速上手

### 4.1 构造 Failure

```dart
const f1 = NetworkFailure();   // 默认 message: 'Network error'
const f2 = NetworkFailure(message: 'Connection timed out');
const f3 = ServerFailure(message: 'User not found', statusCode: 404, code: 'USER_NOT_FOUND');
const f4 = ValidationFailure(message: 'Password too short', field: 'password');
```

### 4.2 在 UI 中分发（穷尽 switch）

```dart
Widget buildError(Failure failure) => switch (failure) {
  NetworkFailure() => const OfflineBanner(),
  ServerFailure(:final statusCode, :final message) => ServerErrorView(code: statusCode, message: message),
  UnauthorizedFailure() => LoginRedirect(),
  ValidationFailure(:final message, :final field) => FieldErrorBubble(field: field, message: message),
  CacheFailure() => const SizedBox.shrink(),   // 缓存失败通常静默
  UnknownFailure(:final message) => ErrorView(message: message),
};
```

如漏掉任一变体（如未来新增 `RateLimitFailure`），Dart 编译器会报错——避免 UI 默默不处理新错误类型。
