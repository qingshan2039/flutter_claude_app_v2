## 3. 设计要点

### 3.1 元数据只在 template

`app_en.arb` 是 template-arb-file，包含每个 key 的 `@key` 元数据（description / placeholders）。`app_zh.arb` 只需 `@@locale` + 各 key 翻译，不重复元数据 — 这是 Flutter gen-l10n 的约定（避免元数据多处维护）。

### 3.2 locale 用短码

文件名 `app_en.arb` / `app_zh.arb`，`@@locale` 为 `en` / `zh`（短码）。spec 提到 zh_CN/en_US，但短码足够（绝大多数 app 不需要区分 zh_CN/zh_TW，需要时再加 `app_zh_TW.arb`）。
