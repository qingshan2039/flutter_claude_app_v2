# T29.2 环境切换 — 验证报告

> 任务 T29.2 / 模块 M29 内置 Debug 面板 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T29.2 实现 `DebugOverrides`（@lazySingleton）：持久化「调试用 BaseUrl 覆盖」（KeyValueStorage），`effectiveBaseUrl(fallback)` 解析「覆盖优先，否则用 EnvConfig 默认」。测试人员可不重装切后端环境。Debug 面板「环境」Tab 设置/清除。4 个单测全绿。

## 1. 任务目标（来自 spec）

T29.2（spec 1068-1070）：运行时切换 BaseUrl，交付物环境切换面板。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 覆盖存储 | `setBaseUrl/clearBaseUrl`（KeyValueStorage key `debug.base_url_override`） |
| 读取 | `baseUrlOverride`（空/未设为 null） |
| 解析 | `effectiveBaseUrl(fallback)` = override ?? fallback |
| 网络接入 | Dio baseUrl resolver 用 `effectiveBaseUrl(envConfig.apiBaseUrl)`（文档化，仅 dev/staging） |
| 面板 | DebugPanelPage「环境」Tab：输入框 + 设置/清除 |

## 3. 快速上手（Quick Start）

```dart
// Dio baseUrl 解析时（dev/staging）：
final base = getIt<DebugOverrides>().effectiveBaseUrl(envConfig.apiBaseUrl);
```
