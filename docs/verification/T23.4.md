# T23.4 iOS 引导更新 — 验证报告

> 任务 T23.4 / 模块 M23 应用内更新 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T23.4 实现 `StoreLauncher`（抽象 + `@LazySingleton` MethodChannel impl）：`openStore(url)` 引导用户跳转 App Store（iOS）/ 应用市场（Android）。channel `flutter_claude_app/store_launcher` 接缝对接 `url_launcher`；未接入/桌面/测试对异常**优雅降级**返回 false。channel-mock 测试验证 url 透传与降级。

## 1. 任务目标（来自 spec）

T23.4（spec 920-922）：引导至 App Store，交付物 iOS 更新实现。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 接口 | `StoreLauncher.openStore(String url) → Future<bool>` |
| iOS | App Store 链接 `https://apps.apple.com/app/idXXXX` 或 `itms-apps://` |
| Android | 应用市场 `market://details?id=...`（同一接口复用） |
| 降级 | `MissingPluginException`/`PlatformException` → false |
| channel | `flutter_claude_app/store_launcher`（生产用 url_launcher `launchUrl(externalApplication)`） |

## 3. 快速上手（Quick Start）

```dart
await getIt<StoreLauncher>().openStore(decision.info.storeUrl!);
```

生产：实现处用 `url_launcher` 的 `launchUrl(Uri.parse(url), mode: LaunchMode.externalApplication)`。

## 5. 与 spec 的偏差与决策

T23.4 决策：iOS 无应用内更新机制，标准做法即引导到 App Store；用 MethodChannel 接缝而非直接依赖 `url_launcher`（保持模板零额外依赖，文档给出 url_launcher 接法），接口同时复用于 Android 市场跳转。
