# T15.2 配置 flutter_flavorizr — 验证报告

> 任务 T15.2 / 模块 M15 多环境配置 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T15.2 提供 `flavorizr.yaml`（三套 flavor 声明式来源），并在 `android/app/build.gradle.kts` 手工实现等价的 `productFlavors`（dev/staging/prod，不同 applicationId 后缀 + AppName）；`AndroidManifest.xml` 的 `android:label` 改为 `${appName}` 占位符。`flutter build apk --flavor dev` 成功产出 APK。

## 1. 任务目标（来自 spec）

T15.2 要求配置 flutter_flavorizr（spec 589-592 行）：三套 flavor、不同 AppId/AppName/Icon，交付物 flavorizr 配置文件。

## 2. 实际配置

| flavor | applicationId | AppName |
|---|---|---|
| dev | `…flutter_claude_app_v2.dev` | CCD Dev |
| staging | `…flutter_claude_app_v2.staging` | CCD Staging |
| prod | `…flutter_claude_app_v2` | CCD |

实现：`build.gradle.kts` → `flavorDimensions += "env"` + `productFlavors{}`（applicationIdSuffix + manifestPlaceholders["appName"]）；manifest `android:label="${appName}"`。

## 3. 快速上手（Quick Start）

```bash
flutter run   --flavor dev     -t lib/main_dev.dart
flutter build apk --flavor prod -t lib/main_prod.dart
# 全新工程一次性生成（含 iOS）：
dart pub global activate flutter_flavorizr && flutter_flavorizr -p flavorizr.yaml
```

## 4. 验收命令与实际输出

```
$ flutter build apk --flavor dev -t lib/main_dev.dart --debug
✓ Built build/app/outputs/flutter-apk/app-dev-debug.apk
```

（产物文件名带 `-dev-`，证明 flavor 维度生效。）

## 5. 与 spec 的偏差与决策

T15.2 关键决策：**未运行**破坏性的 `dart run flutter_flavorizr` 处理器——它会重写 android/ios 原生工程，覆盖本项目既有手工配置（M07 深链 host、M09 权限、iOS CocoaPods 固定、M13 原生启动页、minSdk=24/iOS 13.0）。改为：Android 按 `flavorizr.yaml` **手工实现** productFlavors（additive、安全、可构建验证）；iOS scheme/xcconfig 在 `docs/env/ENVIRONMENTS.md` 文档化。Icon 三套配置见 T15.5。
