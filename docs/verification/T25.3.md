# T25.3 乐观更新 — 验证报告

> 任务 T25.3 / 模块 M25 离线优先架构 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T25.3 实现 `runOptimistic<T>`（泛型纯函数）：**先 emit 乐观状态（UI 立即响应）→ await commit（网络）→ 失败则 emit 回滚到先前状态**，返回 `OptimisticResult{value, committed, error}`。3 个单测全绿（成功保持、失败回滚、乐观态先于网络发射）。

## 1. 任务目标（来自 spec）

T25.3（spec 979-982）：先更 UI 再发请求 + 失败回滚，交付物乐观更新示例。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| API | `runOptimistic<T>({previous, optimistic, emit, commit})` |
| 流程 | `emit(optimistic)` → `commit()` → 成功返回 committed:true；catch → `emit(previous)` 回滚 |
| 结果 | `OptimisticResult{value, committed, error}` |
| 示例 | demo 页「点赞」：先变红+1，commit 失败回滚 + SnackBar |

## 3. 快速上手（Quick Start）

```dart
final r = await runOptimistic<bool>(
  previous: liked,
  optimistic: !liked,
  emit: (v) => setState(() => liked = v),  // 先更 UI
  commit: () => api.setLiked(!liked),       // 发请求
);
if (!r.committed) showError(r.error);       // 已自动回滚
```

## 5. 与 spec 的偏差与决策

T25.3 决策：用**泛型纯函数**而非具体控件，适配任意状态类型与状态管理（setState/Riverpod 皆可，通过 emit 回调）；回滚以「再次 emit 先前值」实现，调用方状态容器无需特殊支持；error 随结果返回供上层提示。无 DI（纯函数）。
