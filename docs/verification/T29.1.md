# T29.1 Debug 入口 — 验证报告

> 任务 T29.1 / 模块 M29 内置 Debug 面板 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T29.1 实现 `DebugEntry`：包住常驻控件（如 LOGO），**长按**触发 `onTrigger`（打开 Debug 面板），仅 `enabled` 时响应；静态 `DebugEntry.isAvailable(env)` 限定 dev/staging（生产禁用）。摇一摇可在此基础上接 `sensors_plus`，本模板用长按零依赖。3 个测试全绿。

## 1. 任务目标（来自 spec）

T29.1（spec 1063-1066）：摇一摇 / 长按 LOGO 触发 + 仅 dev/staging 启用，交付物 Debug 入口。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 触发 | `GestureDetector(onLongPress: enabled ? onTrigger : null)` |
| 门控 | `isAvailable(AppEnvironment env) => !env.isProd`（dev/staging 可用） |
| enabled | 由调用方传入（一般 `DebugEntry.isAvailable(currentEnv)`） |
| 摇一摇 | 文档化（接 sensors_plus 监听加速度），默认长按 |

## 3. 快速上手（Quick Start）

```dart
DebugEntry(
  enabled: DebugEntry.isAvailable(env),
  onTrigger: () => Navigator.push(... DebugPanelPage()),
  child: const FlutterLogo(),
);
```
