# T34.1 动效曲线规范 — 验证报告

> 任务 T34.1 / 模块 M34 动效系统 / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T34.1 在既有 `MotionTokens`（M10/T10.1 已定义时长 fast/normal/slow + 曲线 standard/emphasizedDecelerate/…）基础上补齐动效系统 Token：新增 Material 3 `emphasized` 标准曲线、微交互 `pressable` 曲线、列表交错 `staggerStep` 步长与 `staggerDelay(index)` 助手。全应用动效（转场/入场/微交互）统一从该 Token 取时长与曲线。3 个单测全绿。

## 1. 任务目标（来自 spec）

T34.1（spec 1175-1177）：标准曲线与时长，交付物动效 Token。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 时长（既有 T10.1） | `instant/fast(150)/normal(250)/slow(400)/slowest(600)` |
| 曲线（既有 T10.1） | `standard`、`emphasizedDecelerate`、`emphasizedAccelerate`、`bounce` |
| 新增曲线（T34.1） | `emphasized = Cubic(0.2,0,0,1)`（M3 强调）、`pressable = Curves.easeOut` |
| 交错（T34.1） | `staggerStep = 50ms`；`staggerDelay(index) = staggerStep * index` |

## 3. 快速上手（Quick Start）

```dart
AnimatedAlign(duration: MotionTokens.normal, curve: MotionTokens.emphasized, ...);
// 列表第 i 项入场延迟
AppearAnimation(delay: MotionTokens.staggerDelay(i), child: ...);
```

## 5. 与 spec 的偏差与决策

T34.1 决策：动效 Token **复用并扩展** M10/T10.1 既有的 `MotionTokens`（单一真源），而非另起文件，避免「时长/曲线」散落两处导致节奏漂移；新增项均以 `(T34.1)` 标注。`emphasized` 采用 Material 3 强调缓动 `Cubic(0.2,0,0,1)`，与 M07 路由转场（`PageTransitions`）保持同一视觉语言。
