## 1. 任务目标（spec）

- **交付物**：性能监控工具

## 2. API

| 方法 | 用途 |
|---|---|
| `start(name)` / `stop(name)` | 手动起止；stop 返回 Duration（未 start 返回 null + warning） |
| `traceAsync<T>(name, action)` | 包裹异步（接口耗时）：`await perf.traceAsync('GET /users', () => api.getUsers())` |
| `traceSync<T>(name, action)` | 包裹同步（解析等） |

结果记录格式：`[perf] <name> took <ms>ms`（info 级，经 AppLogger → 脱敏 → 输出）。

## 3. 设计要点

### 3.1 页面加载时间

```dart
// 页面 initState
getIt<PerformanceMonitor>().start('home_load');
// 首帧后
WidgetsBinding.instance.addPostFrameCallback((_) => perf.stop('home_load'));
```

### 3.2 接口耗时

```dart
final users = await perf.traceAsync('GET /users', () => apiService.getUsers());
```

`traceAsync`/`traceSync` 用 try/finally 保证**即使 action 抛异常也记录耗时**（并向上抛异常）。

### 3.3 M27 衔接

当前结果只记 logger。M27 数据埋点完成后，可在 `stop` 中同时上报 analytics / Sentry performance transaction。API 形状已就绪。
