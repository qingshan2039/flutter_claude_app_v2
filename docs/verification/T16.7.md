## 2. 实际配置

| 文件 | 用途 |
|---|---|
| `.github/pull_request_template.md` | PR：Summary / Type / Related / Checklist / How to test |
| `.github/ISSUE_TEMPLATE/bug_report.md` | Bug：复现/期望/环境（flavor/版本） |
| `.github/ISSUE_TEMPLATE/feature_request.md` | Feature：背景/方案/影响范围 |
| `.github/ISSUE_TEMPLATE/config.yml` | `blank_issues_enabled: false` + Discussions 链接 |
