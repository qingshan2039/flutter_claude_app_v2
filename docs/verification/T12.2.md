## 2. 设计要点

### 2.1 LayoutBuilder（父约束，非整窗口）

```dart
LayoutBuilder(builder: (context, constraints) {
  final type = Breakpoints.fromWidth(constraints.maxWidth);
  return _resolve(type)(context);
});
```

用 `constraints.maxWidth`（父容器）而非 `MediaQuery`（整窗口），适合嵌套场景（如某个 Expanded 内部也想响应式）。

### 2.2 就近回退

只 `mobile` 必填；`tablet`/`desktop`/`largeDesktop` 可选：largeDesktop → desktop → tablet → mobile。

### 2.3 ResponsiveValue 选值

```dart
final columns = const ResponsiveValue<int>(mobile: 1, tablet: 2, desktop: 4)
    .resolve(context.screenType);
```

## 3. 实施过程的 Bug 修复

测试 `宽约束 → desktop` / `largeDesktop 回退` 失败：用 `SizedBox(width: 1200)` 包裹 builder，但测试默认 surface 仅 800 宽，SizedBox 被 loose 约束钳制到 800 → LayoutBuilder 看到 tablet 宽度。

**修复**：改用 `tester.view.physicalSize = Size(width, 600)` 设置整窗口宽度，builder 填满窗口，LayoutBuilder 拿到真实 width。
