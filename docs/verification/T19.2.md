# T19.2 首页模块 — 验证报告

> 任务 T19.2 / 模块 M19 示例业务模块 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T19.2 在 `features/home/` 落地信息流首页：`HomePage`（Shell 第一个 Tab）用 M14 的 `AsyncValueWidget`（骨架三态）+ `AppRefreshList`（下拉刷新 + 上拉分页）；`HomeFeedController extends AutoDisposeAsyncNotifier<HomeFeedState>`（pageSize=15，refresh/loadMore）；点列表项 `context.goNamed(detail, pathParameters:{id})`。验收：analyze 0 issue、test 全绿、dev APK 构建成功。

## 1. 任务目标（来自 spec）

T19.2（spec 768-772）：首页模块需覆盖**底部 Tab 嵌套路由、列表加载、下拉刷新 + 分页**，交付物 `features/home/`。

## 2. 实际配置

| 关注点 | 实现 |
|---|---|
| 底部 Tab 嵌套路由 | `app_router.dart` `StatefulShellRoute.indexedStack`，首个分支 `/` → 真 `HomePage`（在 Shell 内，保留 `NavigationBar`） |
| 列表加载 | `HomeRepositoryImpl.fetchFeed(page,pageSize)`（stub：maxPages=4、400ms 延迟、生成「文章 #n」） |
| 三态 | `AsyncValueWidget<HomeFeedState>(skeleton:true, onRetry: invalidate)` |
| 下拉刷新 + 分页 | `AppRefreshList<FeedItem>(items, hasMore, onRefresh: controller.refresh, onLoad: controller.loadMore)` |
| 状态层 | `HomeFeedState{items,hasMore,page}` + `HomeFeedController`（`build()`→第 1 页、`refresh()`→`AsyncValue.guard`、`loadMore()`→追加下一页） |
| 跳详情 | ListTile `onTap` → `context.goNamed(RouteNames.detail, pathParameters:{'id': item.id})` |

## 5. 与 spec 的偏差与决策

T19.2 决策：复用 M14 通用组件（`AsyncValueWidget` + `AppRefreshList`/easy_refresh）而非重写列表逻辑，验证组件库可组装出真实业务页；数据为本地分页 stub（4 页到底）。路由接线只改 `app_router.dart` 指向真 `HomePage`，`/search` 分支仍用 router_demo 占位页（最小爆破面），故 `app_router_test` 仅需改首页/详情/登录断言。
