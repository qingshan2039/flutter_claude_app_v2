## 1. 任务目标（spec）

## 2. 设计要点

### 2.1 LogFileManager（可测核心）

| 能力 | 实现 |
|---|---|
| 按日期切割 | `fileForDate(date)` → `app-2026-05-18.log` |
| 清理过期 | `cleanupExpired(now)` 删早于 `retentionDays` 的文件，返回删除数 |
| 大小限制 | append 前若文件 ≥ `maxFileSizeBytes`，滚动为 `.1` 备份 |
| 串行写入 | `_writeQueue` Future 链，避免并发覆盖 |

### 2.2 FileLogOutput 适配

`FileLogOutput extends LogOutput`，`output(event)` 把 `event.lines` 逐行 `manager.append`（fire-and-forget，由队列串行化）。接入：

```dart
final manager = LogFileManager(directory: await getApplicationSupportDirectory());
await manager.cleanupExpired();
final logger = Logger(output: MultiOutput([ConsoleOutput(), FileLogOutput(manager)]));
```

M13/T13.1 bootstrap 在 path_provider 就绪后构造文件日志（避免 AppLogger 默认构造异步化）。

## 3. 实施过程的 Bug 修复

测试 `output 写入文件` 失败：

```
Expected: contains 'line-a'
  Actual: 'line-b\n'
```

两次 `append('line-a')` / `append('line-b')` 并发（fire-and-forget）race，line-a 丢失。**修复**：`LogFileManager.append` 改为串行写入队列：

```dart
Future<void> _writeQueue = Future<void>.value();
Future<void> append(String line, {DateTime? now}) {
  _writeQueue = _writeQueue.then((_) => _doAppend(line, now: now));
  return _writeQueue;
}
```

并把 `flush: false` 改 `flush: true` 确保写入落盘。这是生产正确性修复（高频日志并发写不会丢/串）。
