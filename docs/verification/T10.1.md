## 3. 设计要点

### 3.1 Token 不被 UI 直接引用

Token 是「原始常量层」。UI 通过 [ColorScheme]（M3 角色色，由 brandSeed 派生）或 [AppColorsExtension]（业务色）间接使用。这样换肤 / 主题切换只改装配层，不动散落的 UI 代码。

### 3.2 业务色单列

success/warning/info 在 M3 ColorScheme 中无对应角色，定义在 color_tokens 并经 [AppColorsExtension]（T10.3）注入主题，亮/暗各一套保证对比度。

### 3.3 快捷方式减少样板

spacing/radius 提供 EdgeInsets/SizedBox/BorderRadius 快捷常量（`SpacingTokens.gapMd`、`RadiusTokens.allLg`），调用点更简洁。
