# T14.7 键盘处理 — 验证报告

> 任务 T14.7 / 模块 M14 通用 UI 组件 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T14.7 在 `lib/shared/utils/keyboard_utils.dart` 提供：`DismissKeyboardOnTap`（点空白处收起键盘）、`KeyboardUtils`（`dismiss` 可脱 context、`inset`/`isOpen` 读键盘高度）、`KeyboardSpacer`（智能避让：高度跟随键盘升降，让底部按钮浮在键盘上）。

## 1. 任务目标（来自 spec）

T14.7 要求键盘处理工具：点击空白收起、智能避让（spec 614-618 行）。

## 2. 实际配置

| spec 期望 | 实际实现 |
|---|---|
| 点击空白收起 | `DismissKeyboardOnTap`（`GestureDetector` + `HitTestBehavior.translucent` + `FocusManager.primaryFocus?.unfocus()`） |
| 智能避让 | `KeyboardSpacer`（`SizedBox(height: viewInsets.bottom + extra)`）放在底部固定内容下方 |
| 工具方法 | `KeyboardUtils.dismiss([context])` / `inset(context)` / `isOpen(context)` |

## 3. 快速上手（Quick Start）

```dart
DismissKeyboardOnTap(child: pageBody);          // 点空白收起
KeyboardUtils.dismiss();                          // 主动收起（无 context）
Column(children: [form, const KeyboardSpacer(extra: 8), submitButton]); // 避让
```

## 4. 验收命令与实际输出

```
$ flutter test test/shared/utils/keyboard_utils_test.dart
00:01 +3: All tests passed!
```

测试覆盖：点空白处焦点移除、`inset`/`isOpen` 读 `viewInsets.bottom=300`、`KeyboardSpacer` 高度 = 键盘高度 + extra（100+8=108）。

## 5. 与 spec 的偏差与决策

T14.7 决策：`KeyboardSpacer` 用 `viewInsets`（而非 `padding`）读键盘高度——`viewInsets.bottom` 才是键盘实际占用高度。`DismissKeyboardOnTap` 用 translucent hit-test，既能在空白区收到点击，又不拦截子组件（按钮/输入框）交互。
