# T34.3 Hero 动画封装 — 验证报告

> 任务 T34.3 / 模块 M34 动效系统 / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T34.3 交付通用 Hero 工具 `AppHero`：在原生 `Hero` 上统一封装——相同 `tag` 包裹来源/目标元素即得共享元素转场；`enabled=false` 时退化为普通 child（按平台/可达性关闭动画）；透传可选 `flightShuttleBuilder`。showcase 提供「缩略图 → 详情放大」的可运行 Hero 示例。2 个单测全绿。

## 1. 任务目标（来自 spec）

T34.3（spec 1183-1185）：通用 Hero 工具，交付物 Hero 示例。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 组件 | `AppHero{required tag, required child, enabled=true, flightShuttleBuilder?}` |
| 共享转场 | 来源/目标页用相同 `tag` 包裹同一逻辑元素 |
| 降级 | `enabled=false` → 直接渲染 `child`（不入 Hero） |
| 高级 | `flightShuttleBuilder` 透传（默认用框架内置，对图片/容器稳定） |
| 示例 | `motion_demo_page.dart`：72px logo → 详情页 200px（同 tag `motion-hero-demo`） |

## 3. 快速上手（Quick Start）

```dart
// 列表页
AppHero(tag: 'photo-$id', child: Thumbnail(id));
// 详情页（相同 tag → 自动共享元素飞行）
AppHero(tag: 'photo-$id', child: BigImage(id));
```

## 5. 与 spec 的偏差与决策

T34.3 决策：`AppHero` 做**薄封装**而非重造 Hero——核心价值是统一「tag 约定 + 可关闭(enabled) + 可选 shuttle 透传」，默认沿用 Flutter 内置 flight shuttle（对图片/渐变容器稳定，避免自定义 shuttle 引入飞行期布局抖动）。示例用渐变容器 + 图标（非网络图）保证 Hero 飞行在 demo/测试中稳定无外部依赖。
