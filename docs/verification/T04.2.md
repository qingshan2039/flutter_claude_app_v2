## 2. 设计要点

### 2.1 默认脱敏白名单

| 类别 | 默认值 |
|---|---|
| Headers | `authorization`、`cookie`、`set-cookie`、`x-api-key`（大小写不敏感） |
| Body keys | `password`、`token`、`access_token`、`refresh_token`、`secret`、`apiKey`、`api_key` |

构造函数接受 `extraSensitiveHeaders` / `extraSensitiveBodyKeys` 扩展业务专属字段。

### 2.2 递归脱敏算法

公开方法 `sanitizeBody(Object?)`：
- `Map` → 复制并对每个 entry 检查 key
- `List` → 对每个元素递归调用
- 其它原始类型 → 原样返回

### 2.3 release 零开销

`enabled = kDebugMode` 默认。`onRequest` / `onResponse` / `onError` 第一行 `if (enabled)` 短路；release 编译期 `kDebugMode = false`，整段被 tree-shake 掉。
