## 3. 使用示例

### 3.1 单个权限

```dart
final svc = getIt<PermissionService>();
final status = await svc.request(AppPermission.camera);
if (status.isGranted) { openCamera(); }
```

### 3.2 批量请求

```dart
final results = await svc.requestAll(<AppPermission>[
  AppPermission.camera,
  AppPermission.microphone,
]);
// results: { camera: granted, microphone: denied }
```
