## 1. 任务目标（spec）

## 2. 配置

```yaml
flutter_native_splash:
  color: "#6750A4"          # 品牌 seed（对齐 M10 ColorTokens.brandSeed）
  color_dark: "#1C1B1F"
  android_12:
    color: "#6750A4"
    color_dark: "#1C1B1F"
  android: true
  ios: true
```

纯背景色（无图片）即生效；接真实 logo 时取消 `image:` 注释提供 asset。

## 3. 生成的原生资源

`dart run flutter_native_splash:create` 产出：

| 平台 | 文件 |
|---|---|
| Android | `res/drawable/launch_background.xml` + `drawable-v21` + `drawable-night*` |
| Android 12+ | `res/values-v31/styles.xml` + `values-night-v31/styles.xml`（SplashScreen API） |
| iOS | LaunchScreen 资源 + Info.plist 状态栏 |

## 4. 衔接原理

- **系统冷启动**：OS 显示原生启动页（本配置的纯色背景），覆盖引擎初始化的空白期
- **Flutter 引擎就绪**：首帧渲染，原生启动页移除
- 背景色与 [AppTheme] 的 surface/seed 一致 → 视觉无跳变
