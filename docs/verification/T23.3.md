# T23.3 Android 应用内更新 — 验证报告

> 任务 T23.3 / 模块 M23 应用内更新 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T23.3 实现 `AndroidInAppUpdate`（抽象 + `@LazySingleton` MethodChannel impl）：`checkAvailability` / `startImmediateUpdate`（强制全屏）/ `startFlexibleUpdate`（后台下载）。channel `flutter_claude_app/in_app_update` 作为接缝对接 Play Core；非 Android/未接入/测试环境对 `MissingPluginException` 与 `PlatformException` **优雅降级**（unknown/false）。channel-mock 测试覆盖正常与降级。

## 1. 任务目标（来自 spec）

T23.3（spec 916-918）：in-app update API 集成，交付物 Android 更新实现。

## 2. 实际配置

| 方法 | 语义 |
|---|---|
| `checkAvailability()` | → `AndroidUpdateAvailability.{available, notAvailable, unknown}` |
| `startImmediateUpdate()` | immediate：全屏阻塞更新（适合强制） |
| `startFlexibleUpdate()` | flexible：后台下载、完成后提示重启（适合可选） |
| 降级 | `MissingPluginException`/`PlatformException` → unknown/false（不崩溃） |
| channel | `flutter_claude_app/in_app_update`（对接 Play Core / in_app_update 包） |

## 3. 快速上手（Quick Start）

```dart
final updater = getIt<AndroidInAppUpdate>();
if (await updater.checkAvailability() == AndroidUpdateAvailability.available) {
  await updater.startImmediateUpdate();   // 或 startFlexibleUpdate()
}
```

生产：在原生 `MainActivity` 接入 Play Core AppUpdateManager，按 channel 方法名实现。
