| 项 | 实现 |
|---|---|
| 依赖 | `mocktail: ^1.0.5`（dev） |

## 3. 快速上手（Quick Start）

```dart
import '../../../../_helpers/mocks.dart';

final ds = MockAuthRemoteDataSource();
when(() => ds.fetchUser(userId: any(named: 'userId')))
    .thenAnswer((_) async => const UserModel(id: '1', name: 'A', email: 'a@b'));
verify(() => ds.fetchUser(userId: 'x')).called(1);
```

## 5. 与 spec 的偏差与决策

T17.2 决策：`registerCommonFallbackValues()` 仅在用 `any()` 匹配**非基元**参数时才需调用（基元/可空类型不需要），作为工具备用。本项目当前用例参数多为 `String?`，故大多数测试无需注册 fallback。
