## TL;DR

T29.3 实现 `DebugLogStore`（@lazySingleton 环形缓冲）：`add` 记录、超 `capacity` 丢最旧、`filter(minLevel, query)` 级别+关键词过滤、`exportAsText` 一键导出、`clear`。Debug 面板「日志」Tab 提供搜索框 + 级别下拉 + 列表 + 清空/导出（复制到剪贴板）。6 个单测全绿。

## 1. 任务目标（来自 spec）

T29.3（spec 1072-1076）：实时日志展示 + 过滤/搜索 + 一键导出，交付物日志查看器。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 缓冲 | 环形（默认 capacity 500，超出丢最旧） |
| 级别 | `DebugLogLevel{trace,debug,info,warning,error}` |
| 过滤 | `filter(minLevel, query)`（关键词不区分大小写） |
| 导出 | `exportAsText()`（面板复制到剪贴板） |
| 接入 | 在 AppLogger 自定义 Output 调 `add`（M11 集成点，文档化） |

## 3. 快速上手（Quick Start）

```dart
getIt<DebugLogStore>().add(DebugLogLevel.info, 'user login');
final errors = getIt<DebugLogStore>().filter(minLevel: DebugLogLevel.warning);
```
