# T31.3 灰度回滚 — 验证报告

> 任务 T31.3 / 模块 M31 灰度发布与 A/B Test / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T31.3 实现 `ExperimentRollback`（@lazySingleton）：一键 `rollback(key)` 把实验下线（所有用户回落对照组，持久化、重启仍生效）、`restore`/`restoreAll` 恢复；`ExperimentService.resolve` 在「已回滚」时返回 control（forcedControl）。并交付文档 `docs/experiment/AB_TESTING.md`（含客户端回滚 + 服务端 RemoteConfig 回滚两条路径）。3 个单测全绿。

## 1. 任务目标（来自 spec）

T31.3（spec 1127-1129）：一键回滚机制，交付物回滚工具 + 文档。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 一键回滚 | `rollback(experimentKey)`（KeyValueStorage StringList 持久化） |
| 恢复 | `restore(key)` / `restoreAll()` |
| 查询 | `isRolledBack(key)` / `rolledBack()` |
| 生效 | `ExperimentService.resolve` 回滚时强制对照组（forcedControl=true） |
| 两条路径 | 客户端 rollback（本地紧急）/ 服务端经 RemoteConfig 下发 enabled=false（全量推荐） |
| 文档 | `docs/experiment/AB_TESTING.md` |

## 3. 快速上手（Quick Start）

```dart
await getIt<ExperimentRollback>().rollback('button_color'); // 一键下线
// 之后 resolve/activate 全返回 control
await getIt<ExperimentRollback>().restore('button_color');  // 恢复
```

## 5. 与 spec 的偏差与决策

T31.3 决策：提供**客户端 + 服务端**两条回滚路径——客户端 `rollback` 用于本地/紧急快速止血（持久化），生产推荐服务端经 RemoteConfig（M28）下发 `enabled=false` 全量统一关停；回滚一律回落 `control` 对照组（基线行为）。文档 `AB_TESTING.md` 串起分桶/实验/上报/回滚全流程。
