# T18.3 iOS ATS 配置 — 验证报告

> 任务 T18.3 / 模块 M18 安全规范 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T18.3 在 `ios/Runner/Info.plist` 加 `NSAppTransportSecurity`，`NSAllowsArbitraryLoads=false`（默认禁明文、强制 HTTPS），并提供 `NSExceptionDomains` 按域名最小化放开的注释模板。

## 1. 任务目标（来自 spec）

T18.3（spec 740-743）：Info.plist 配置，交付物 iOS 安全配置。

## 2. 实际配置

```xml
<key>NSAppTransportSecurity</key>
<dict>
  <key>NSAllowsArbitraryLoads</key>
  <false/>
  <!-- 需放开时在 NSExceptionDomains 按域名配置 NSExceptionMinimumTLSVersion 等 -->
</dict>
```

## 3. 快速上手（Quick Start）

默认即强制 HTTPS。需对某域名放开：取消 `NSExceptionDomains` 注释，按域名最小化配置，**勿**把 `NSAllowsArbitraryLoads` 设为 true（App Store 审核会要求理由）。

## 4. 验收命令与实际输出

```
$ plutil -lint ios/Runner/Info.plist
ios/Runner/Info.plist: OK
```

（plist 合法；ATS 键值正确嵌入。）

## 5. 与 spec 的偏差与决策

T18.3 决策：显式写 `NSAllowsArbitraryLoads=false`（虽与系统默认一致），以**声明意图**并防止他人误开；例外域以注释模板提供，引导「按域名最小化」而非全局放开。
