# T22.2 颜色对比度检查 — 验证报告

> 任务 T22.2 / 模块 M22 无障碍 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T22.2 实现 `WcagContrast`（`lib/core/theme/a11y/wcag_contrast.dart`）：相对亮度、对比度比值、`meetsAA/meetsAAA`、`grade` 评级；单测把它当**检查工具**校验 Design Token 的业务语义色（success/warning/info，亮/暗各 3 对）全部满足 WCAG AA（≥4.5:1），并打印**对比度报告**。

## 1. 任务目标（来自 spec）

T22.2（spec 883-886）：设计 Token 满足 WCAG AA + 检查工具集成，交付物对比度检查报告。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 检查工具 | `WcagContrast.relativeLuminance/ratio/meetsAA/meetsAAA/grade`（sRGB 线性化 + 0.2126/0.7152/0.0722 加权） |
| Token 校验 | 单测断言 6 对业务语义色 ≥ AA；同时 `debugPrint` 对比度报告 |
| 阈值 | AA 4.5(普通)/3(大)；AAA 7/4.5 |
| 颜色 API | 用 `Color.r/.g/.b`（0..1 双精度，非废弃的 .red/.green/.blue） |

## 3. 快速上手（Quick Start）

```dart
WcagContrast.ratio(Colors.white, brand);                     // 5.13
WcagContrast.meetsAA(foreground: fg, background: bg);        // true/false
WcagContrast.grade(fg, bg);                                  // 'AAA'/'AA'/'AA Large'/'Fail'
```

**对比度报告结论**：全部 6 对业务语义色（亮/暗 × success/warning/info）均 ≥ WCAG AA 4.5:1（warning 达 AAA）。M3 `ColorScheme.fromSeed` 生成的角色对（primary/onPrimary 等）由框架保证对比度，业务统一用配对 `on*` 色。

## 5. 与 spec 的偏差与决策

T22.2 决策：检查工具自研（零依赖、可单测、可运行时用），用 `Color.r/.g/.b`（0..1）避免 `.red/.green/.blue` 废弃告警。「检查报告」以**可复跑的单测 + 打印**形式交付（而非静态截图），数据始终与当前 Token 同步。
