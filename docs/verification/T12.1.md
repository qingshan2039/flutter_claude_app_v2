## 2. 设计要点

```dart
static ScreenType fromWidth(double width) {
  if (width < mobileMax) return ScreenType.mobile;     // <600
  if (width < tabletMax) return ScreenType.tablet;     // <1024
  if (width < desktopMax) return ScreenType.desktop;   // <1440
  return ScreenType.largeDesktop;                       // ≥1440
}
```

`ResponsiveContext` 扩展基于 `MediaQuery.sizeOf`（整窗口）。基于父容器约束的判定用 [ResponsiveBuilder]（T12.2，走 LayoutBuilder）。
