## 2. bootstrap 编排顺序

```dart
void bootstrap(AppEnvironment environment) {
  runZonedGuarded(() async {                          // M03 zone 兜底
    WidgetsFlutterBinding.ensureInitialized();
    await configureDependencies(environment: ...);    // M02 DI（含存储 @preResolve）
    final logger = getIt<AppLogger>();                // M11
    final crashReporter = getIt<CrashReporter>();     // M11
    registerGlobalErrorHandlers(reporter: report);    // M03 ← 回填 AppLogger+CrashReporter
    listenIsolateErrors(reporter: report);            // M03
    await crashReporter.setTag('environment', ...);
    runApp(ProviderScope(observers: [getIt<AppProviderObserver>()], child: App())); // M06 + 首帧
    WidgetsBinding.instance.addPostFrameCallback((_) => _initDeferred(logger)); // T13.3
  }, onZoneError);
}
```

## 4. 占位回填（关键收益）

M03/T03.5 的 `GlobalErrorHandler` 当时用 `debugPrint` 占位。T13.1 把 reporter 回填：

```dart
void report(Object error, StackTrace stackTrace) {
  logger.e('Uncaught error', error: error, stackTrace: stackTrace);   // M11 AppLogger
  unawaited(crashReporter.recordError(error, stackTrace, fatal: true)); // M11 CrashReporter
}
registerGlobalErrorHandlers(reporter: report);
```

zone 兜底回调防御性 `getIt.isRegistered` 检查（DI 可能尚未就绪）。
