# T24.4 数据导出 — 验证报告

> 任务 T24.4 / 模块 M24 隐私合规 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T24.4 实现 `DataExportService`（@lazySingleton）：各模块实现 `DataExportSource{section, collect()}` 并注册，服务聚合为 `{exportedAt, sections:{...}}` 并 `exportAsJson()`（缩进 JSON），满足 GDPR 数据可移植权。3 个单测全绿。

## 1. 任务目标（来自 spec）

T24.4（spec 950-953）：用户数据打包导出 + GDPR 合规，交付物数据导出功能。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 来源 | `DataExportSource{String section; Future<Map> collect()}`（各模块贡献） |
| 注册 | `register(source)`（级联） |
| 聚合 | `buildExport()` → `{exportedAt, sections:{section: data}}` |
| 序列化 | `exportAsJson()`（`JsonEncoder.withIndent('  ')`） |
| GDPR | 数据可移植：结构化、机器可读、含导出时间 |

## 3. 快速上手（Quick Start）

```dart
getIt<DataExportService>()
  ..register(ProfileExportSource())
  ..register(SettingsExportSource());
final json = await getIt<DataExportService>().exportAsJson();
// 写文件 / 分享给用户
```

## 5. 与 spec 的偏差与决策

T24.4 决策：用**来源注册**模式而非集中收集，让各模块自管导出字段（解耦、可扩展）；输出 JSON（机器可读、跨平台），写文件/分享留给调用方（path_provider/share）。demo 页用示例来源演示并弹窗展示 JSON。
