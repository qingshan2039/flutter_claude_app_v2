## 2. 设计要点

### 2.1 为何需要引导

权限 `permanentlyDenied` / `restricted` 后，系统**不再弹原生授权框**。再调 `request()` 直接返回拒绝。唯一出路：引导用户去「系统设置 → 应用 → 权限」手动开启。

### 2.2 两个 API

**`showSettingsDialog`**（静态）— 纯二次说明对话框：

```dart
final opened = await PermissionGuide.showSettingsDialog(
  context,
  title: 'Camera needed',
  message: 'Enable camera in Settings to scan codes.',
  service: getIt<PermissionService>(),
);
// 用户点「Open settings」→ 调 service.openSettings() → 返回 true
// 用户点「Not now」→ 返回 false
```

**`ensureGranted`**（实例）— 一站式：

```dart
final guide = PermissionGuide(getIt<PermissionService>());
final ok = await guide.ensureGranted(
  context,
  AppPermission.camera,
  rationaleTitle: 'Camera needed',
  rationaleMessage: 'Enable in settings',
);
// 已授予 → true（无对话框）
// 永久拒绝 → 弹引导对话框 → false（用户需返回前台后重新 check）
```

### 2.3 context.mounted 防护

`ensureGranted` 在 await（异步请求）之后用 `context.mounted` 守卫再操作 context，避免「Widget 已销毁还用旧 context」的运行时报错。
