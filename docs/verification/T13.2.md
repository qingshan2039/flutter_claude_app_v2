## 2. AppEnvironment 枚举

```dart
enum AppEnvironment {
  dev, staging, prod;
  String get injectableName => name;     // 传给 configureDependencies
  bool get isReleaseLike => this == staging || this == prod;
}
```

`injectableName` 对接 M02 injectable 的 `@dev`/`@prod`/`@Environment('staging')`。M15/T15.1 会把它扩展为完整 `EnvConfig`（baseUrl/flag 等）。
