## TL;DR

T18.5 实现 `DeviceIntegrityService`（seam + MethodChannel impl + `DeviceIntegrityReport`）；Android `MainActivity.kt` 粗检（模拟器/可调试/su 路径）。未实现平台返回默认「可信」（保守不误杀）。文档建议生产换专门方案。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 接口 | `DeviceIntegrityService { Future<DeviceIntegrityReport> check(); }` |
| 报告 | `DeviceIntegrityReport`：isRootedOrJailbroken / isEmulator / isDebuggable + `isTrusted` |
| 实现 | MethodChannel `flutter_claude_app/device_integrity`；MissingPlugin → 默认可信 |
| 原生 | Android：FINGERPRINT/MODEL/HARDWARE 判模拟器、FLAG_DEBUGGABLE、su 路径粗检 |

## 5. 与 spec 的偏差与决策

T18.5 决策：提供**统一接口（seam）+ Android 粗检 + 安全默认**，而非内置重型检测库——越狱/Root 检测是攻防对抗，生产应集成 **Play Integrity API**（Android）/ **DeviceCheck + App Attest**（iOS）/ `flutter_jailbreak_detection`，替换 impl 而不动业务。默认「可信」避免误杀正常用户（拦截策略由业务决定）。
