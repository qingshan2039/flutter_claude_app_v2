## 5. 与 spec 的偏差与决策（重要）

T16.1 关键教训：**`avoid_redundant_argument_values` + `dart fix` 一起会引入静默 bug**。`EnvConfig.resolve` 里 `enableLogging: hasLogging ? logging : null`——在「无 dart-define」构建下 `bool.hasEnvironment(...)` 是 const `false`，整个三元式被编译期折叠成 `null`（= copyWith 默认值），于是该规则判定「实参冗余」，`dart fix` 直接删掉这行。结果：**带 `--dart-define=ENABLE_LOGGING=true` 的构建会静默丢失覆盖**。已恢复该行、关闭该规则，并加注释警示。

其余决策：`@immutable` 加到 `EnvConfig` 与 `Result`（修 avoid_equals_and_hash_code_on_mutable_classes）；`dart fix` 误把 `injection_test.dart` 的 `expect(() => getIt<T>(), throwsStateError)` 改坏（unnecessary_lambdas），已手工修回。
