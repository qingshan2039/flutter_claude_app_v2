## 2. 实现

```dart
// typed_routes.dart
@TypedGoRoute<DetailRoute>(path: '/typed-detail/:id', name: 'typed-detail')
class DetailRoute extends GoRouteData with $DetailRoute {
  const DetailRoute({required this.id});
  final String id;

  @override
  Widget build(BuildContext context, GoRouterState state) =>
      DetailPage(id: id);
}
```

生成代码（`typed_routes.g.dart` 片段）：

```dart
List<RouteBase> get $appRoutes => [$detailRoute];

RouteBase get $detailRoute => GoRouteData.$route(
  path: '/typed-detail/:id',
  name: 'typed-detail',
  factory: $DetailRoute._fromState,
);

mixin $DetailRoute on GoRouteData {
  static DetailRoute _fromState(GoRouterState state) =>
      DetailRoute(id: state.pathParameters['id']!);
  // ...location / go / push / replace 等扩展
}
```

## 3. 实施过程中的版本兼容问题

| 阶段 | 问题 | 修复 |
|---|---|---|
| 首版用 `go_router_builder: ^2.7.0` | 与 freezed 3.x 的 build_runner 链冲突 | 升到 `^4.3.0` |
| `^4.3.0` + go_router 14.x | TypedGoRoute 缺 `caseSensitive` 字段 | 升 go_router 到 `^15.0.0` |
| go_router 15.x + 旧 mixin 名 | `with _$DetailRoute` 找不到 | 改为 `with $DetailRoute`（去下划线） |

最终：`go_router 15.1.3 + go_router_builder 4.3.0` 全部跑通。

## 5. 设计决策

### 5.1 类型安全路由仅做示范，不强制全部迁移

主路由表（home / search / settings / detail / login）保持**手写 GoRoute** 模式，原因：
- Shell 内的多 branch 结构在类型安全 API 中写起来更冗长
- 手写更直观，新人易读

`DetailRoute` 作为单条类型安全示例。**模板使用者**可根据需要把更多路由改为类型安全。

### 5.2 与 [appRouter] 的集成

```dart
GoRouter(
  routes: [
    StatefulShellRoute(...),
    GoRoute(...),
    ...$appRoutes,  // ← spread 类型安全路由进列表
  ],
);
```

两种风格共存无冲突。
