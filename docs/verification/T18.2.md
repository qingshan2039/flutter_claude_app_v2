# T18.2 Android 网络安全配置 — 验证报告

> 任务 T18.2 / 模块 M18 安全规范 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T18.2 新增 `network_security_config.xml`（release 禁明文强制 HTTPS、debug 放开本地明文+用户证书、pinning 示例注释），并经 AndroidManifest `android:networkSecurityConfig` 接入。dev debug APK 构建通过。

## 1. 任务目标（来自 spec）

T18.2（spec 736-739）：network_security_config.xml，交付物 Android 安全配置。

## 2. 实际配置

| 段 | 作用 |
|---|---|
| `base-config cleartextTrafficPermitted="false"` | release 强制 HTTPS |
| `debug-overrides`（system+user 证书） | 仅 debug 放开明文 + 抓包；release 不受影响 |
| `domain-config`/`pin-set`（注释示例） | 证书绑定模板，上线按真实域名 + 备份 pin 启用 |

接入：`AndroidManifest.xml` `<application android:networkSecurityConfig="@xml/network_security_config">`。

## 3. 快速上手（Quick Start）

默认即生效。启用 pinning：取消 `network_security_config.xml` 中 `domain-config` 注释，替换域名与 SHA-256 SPKI pin（含备份 pin + 过期日）。

## 5. 与 spec 的偏差与决策

T18.2 决策：用 `debug-overrides` 而非全局放开——release 始终强制 HTTPS 且不信任用户证书，仅 debug 构建放开本地明文/抓包，避免「调试方便」泄漏到生产。pinning 默认注释（需真实域名/证书），文档强调备份 pin。
