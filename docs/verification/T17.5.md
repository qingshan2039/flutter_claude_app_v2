# T17.5 覆盖率配置 — 验证报告

> 任务 T17.5 / 模块 M17 测试体系 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T17.5 新增 `scripts/coverage.sh`：跑 `flutter test --coverage` → 生成 `coverage/lcov.info` → （有 lcov 时）过滤生成代码 → 用 awk 直接算行覆盖率（跨 lcov 版本稳定）。CI 增加 `--coverage` 并上传 lcov artifact。实测行覆盖 **77.3%**。

## 1. 任务目标（来自 spec）

T17.5（spec 703-707）：lcov 配置、CI 报告生成，交付物覆盖率脚本。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 收集 | `flutter test --coverage` → `coverage/lcov.info`（已 gitignore） |
| 过滤 | 有 `lcov` 时移除 `*.g.dart`/`*.freezed.dart`/`*.config.dart`/`*.gen.dart`/l10n/入口（容错，版本差异不报错） |
| 摘要 | awk 从 lcov.info 累加 `LF`/`LH`，无需 lcov 也能出数字 |
| HTML | `scripts/coverage.sh --html` → `coverage/html/`（需 genhtml） |
| CI | `flutter test --coverage` + upload-artifact `coverage/lcov.info` |

## 3. 快速上手（Quick Start）


## 5. 与 spec 的偏差与决策

T17.5 决策：覆盖率摘要用 **awk 直接解析 lcov.info**，而非依赖 `lcov --summary`——
不同平台 lcov 版本（1.x / 2.x）参数与报错行为差异大，awk 方案零依赖、稳定。
lcov 过滤为「可选增强」（装了才执行，且容错），不装也能出原始覆盖率。
`coverage/` 已在 `.gitignore`，不入库；CI 以 artifact 形式上传。
