# T15.3 Dart Define 注入 — 验证报告

> 任务 T15.3 / 模块 M15 多环境配置 / 优先级 P0 / 状态 ✅ completed / 验证 2026-05-23

## TL;DR

T15.3 用 `--dart-define-from-file=env/<env>.json` 注入编译期常量；真实 `env/*.json`（含 API/DSN 等敏感值）被 `.gitignore`，仓库只提交 `env/*.example.json` 模板。构建脚本 `scripts/flutter-env.sh` 封装 flavor + 入口 + define 文件。`EnvConfig.resolve` 读取这些 define。

## 1. 任务目标（来自 spec）

T15.3 要求 Dart Define 注入（spec 593-598 行）：编译时常量注入示例、敏感配置不入代码库，交付物构建脚本 + 文档。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 注入方式 | `--dart-define-from-file=env/<env>.json`（Flutter 3.7+ JSON 文件，支持 string/bool/num） |
| 敏感不入库 | `.gitignore`：`/env/*.json` 忽略，`!/env/*.example.json` 保留模板 |
| 读取 | `EnvConfig.resolve`：`String/bool.fromEnvironment` 读 API_BASE_URL/SENTRY_DSN/APP_NAME/ENABLE_LOGGING/ENABLE_CRASH_REPORTING |
| 脚本 | `scripts/flutter-env.sh <env> <run\|build-apk\|build-appbundle\|build-ios>` |

## 3. 快速上手（Quick Start）

```bash
cp env/dev.example.json env/dev.json     # 填真实值
scripts/flutter-env.sh dev run
# 手写等价：
flutter run --flavor dev -t lib/main_dev.dart --dart-define-from-file=env/dev.json
```

## 5. 与 spec 的偏差与决策

T15.3 决策：用 `--dart-define-from-file`（JSON 文件）而非散落的多个 `--dart-define`，既集中管理又能按环境切换。EnvConfig 把 dart-define 作为「覆盖层」叠加在每环境默认值上：未注入时回退默认值，保证缺 `env/*.json` 也能跑（用内置默认）。
