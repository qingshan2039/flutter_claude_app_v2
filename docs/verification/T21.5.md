# T21.5 包体积优化 — 验证报告

> 任务 T21.5 / 模块 M21 性能优化体系 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T21.5 交付包体积优化「配置 + 脚本」：`scripts/analyze_size.sh`（`flutter build --analyze-size` 体积明细 + DevTools App Size JSON）、`scripts/check_unused_assets.sh`（启发式未用资源检测，支持 `--strict`）、`build_android.sh` 增加 **`--split-per-abi`** ABI 拆分；字体子集化（release 默认 `--tree-shake-icons`）与资源压缩（R8/AAB 分发）在 [PERFORMANCE §4](../PERFORMANCE.md#4-包体积优化t215) 文档化。

## 1. 任务目标（来自 spec）

T21.5（spec 863-867）：ABI 拆分 + 资源压缩 + 字体子集化 + 未使用资源检测脚本，交付物优化配置 + 脚本。

## 2. 实际配置

| spec 要求 | 实现 |
|---|---|
| ABI 拆分 | `build_android.sh prod apk --split-per-abi`（每 ABI 单包 ≈ universal 的 1/3）；AAB 由 Play 自动分发 |
| 资源压缩 | 文档化：release `--obfuscate`、Android R8 `minifyEnabled`/`shrinkResources`、AAB 按设备切分 |
| 字体子集化 | release 默认 `--tree-shake-icons`（只打包用到的图标字形）；自定义字体 fontTools 子集化 |
| 未使用资源检测 | `scripts/check_unused_assets.sh`：扫 `assets/` 在 `lib/` 查引用（含 flutter_gen 生成引用），`--strict` 可 CI 拦截 |
| 体积分析 | `scripts/analyze_size.sh`：`--analyze-size` 明细 + DevTools App Size JSON |

## 3. 快速上手（Quick Start）

```bash
scripts/analyze_size.sh prod apk android-arm64     # 体积明细
scripts/check_unused_assets.sh assets              # 未用资源
scripts/build_android.sh prod apk --split-per-abi  # 按 ABI 拆分 APK
```

## 5. 与 spec 的偏差与决策

T21.5 决策：未用资源检测用 **shell 脚本启发式**（按 basename 匹配，零依赖、可入 CI），并明确标注「动态拼接路径可能误报，删前人工复核」；ABI 拆分对 AAB 给出提示（Play 自动分发，无需手动 split）。资源压缩/字体子集化在 Flutter 中主要是构建开关与平台配置，故以文档 + 脚本参数承载，而非额外代码。
