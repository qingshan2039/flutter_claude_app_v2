# T32.1 LLM SDK 抽象层 — 验证报告

> 任务 T32.1 / 模块 M32 AI 能力集成预留 / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T32.1 定义厂商无关的统一 LLM 接口 `LlmClient`（`complete` 非流式 + `stream` 流式）与请求/响应模型（`LlmMessage`/`LlmRequest`/`LlmResponse`/`LlmChunk`），并提供 `@LazySingleton(as: LlmClient)` 的桩实现 `StubLlmClient`（本地模拟、免 API Key、不联网）。业务层只依赖接口，接 Anthropic/OpenAI/国内大模型时新增适配 + 改 DI 绑定即可。3 个单测全绿。

## 1. 任务目标（来自 spec）

T32.1（spec 1135-1138）：统一 LLM 接口，支持 Anthropic / OpenAI / 国内大模型，交付物 `core/ai/`。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 角色 | `enum LlmRole { system, user, assistant }` |
| 消息 | `LlmMessage(role, content)` + `.system/.user/.assistant` 便捷构造 |
| 请求 | `LlmRequest{messages, model, temperature=0.7, maxTokens=1024}` |
| 非流式响应 | `LlmResponse{text, model, tokens?}` |
| 流式分片 | `LlmChunk(delta, {done=false})` |
| 接口 | `abstract LlmClient { Future<LlmResponse> complete(req); Stream<LlmChunk> stream(req); }` |
| 桩实现 | `StubLlmClient`（`@LazySingleton(as: LlmClient)`）：回显最后一条 user 消息；`complete` 延迟 200ms；`stream` 逐字 16ms 一片，末片 `LlmChunk('', done: true)` |
| 接真实厂商 | 文档注明 Anthropic `/v1/messages`（SSE）、OpenAI `/v1/chat/completions`（`stream:true`）、国内（通义/文心/讯飞）适配点 |

## 3. 快速上手（Quick Start）

```dart
final client = getIt<LlmClient>(); // 默认绑定 StubLlmClient
final req = LlmRequest(model: 'demo', messages: [const LlmMessage.user('你好')]);
final res = await client.complete(req);           // 一次性
await for (final c in client.stream(req)) { ... } // 流式（c.delta / c.done）
```

## 5. 与 spec 的偏差与决策

T32.1 决策：本模块为「集成预留」，故交付**厂商无关抽象 + 可运行桩实现**而非绑定某家 SDK——既能立刻跑通 UI/测试（免 Key、不联网），又把厂商差异隔离在 `LlmClient` 实现后。生产接入：用 M04 的 Dio 实现 `AnthropicLlmClient`/`OpenAiLlmClient` 等，`@LazySingleton(as: LlmClient)` 改绑即可，业务零改动。请求/响应模型保持厂商中立（role/content/delta），SSE 流解析复用 T32.2 的 `SseParser`。
