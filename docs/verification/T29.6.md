# T29.6 设备信息 — 验证报告

> 任务 T29.6 / 模块 M29 内置 Debug 面板 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T29.6 实现 `DeviceInfoService`（@lazySingleton）：用 `dart:io` 的 `Platform` 零依赖给出设备/系统信息快照（操作系统、系统版本、App 版本、Dart 版本、CPU 核心数、locale）。Debug 面板「设备」Tab 列表展示。1 个单测覆盖。

## 1. 任务目标（来自 spec）

T29.6（spec 1087-1089）：设备型号、系统版本、App 版本，交付物设备信息页。

## 2. 实际配置

| 字段 | 来源 |
|---|---|
| 操作系统 | `Platform.operatingSystem` |
| 系统版本 | `Platform.operatingSystemVersion` |
| App 版本 | `--dart-define=APP_VERSION`（缺省 1.0.0） |
| Dart 版本 | `Platform.version` |
| CPU 核心数 / locale | `Platform.numberOfProcessors` / `localeName` |
| 机型/精确版本 | 文档化（device_info_plus / package_info_plus） |

## 3. 快速上手（Quick Start）

```dart
final info = getIt<DeviceInfoService>().snapshot(); // Map<String,String>
```

T29.6 决策：用 `dart:io Platform` 零依赖提供核心设备/系统信息；厂商机型与精确 App 版本需 `device_info_plus`/`package_info_plus`，文档化（App 版本暂用 dart-define 注入兜底），保持模板零新增依赖。
