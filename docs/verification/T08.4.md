## 2. 设计要点

### 2.1 Locale? 状态（null = 跟随系统）

```dart
class LocaleNotifier extends Notifier<Locale?> {
  @override
  Locale? build() { ... }              // 启动读持久化
  Future<void> setLocale(Locale? locale) async { ... }
  Future<void> useSystemLocale() => setLocale(null);
}

final localeProvider = NotifierProvider<LocaleNotifier, Locale?>(LocaleNotifier.new);
```

### 2.2 MaterialApp 绑定（即时生效）

```dart
final locale = ref.watch(localeProvider);
MaterialApp(
  locale: locale,                                  // null → Flutter 跟随系统
  supportedLocales: kSupportedLocales,
  localizationsDelegates: AppLocalizations.localizationsDelegates,
);
```

`ref.watch(localeProvider)` 让 MaterialApp 订阅 locale 变化；`setLocale` 改 state → MaterialApp 重建 → 整个 UI 立即切换语言。无需重启 app。

### 2.3 切换 UI 调用

```dart
ref.read(localeProvider.notifier).setLocale(const Locale('zh'));   // 切中文
ref.read(localeProvider.notifier).useSystemLocale();              // 跟随系统
```
