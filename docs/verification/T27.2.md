# T27.2 自动页面埋点 — 验证报告

> 任务 T27.2 / 模块 M27 数据埋点 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T27.2 实现 `AnalyticsRouteObserver`（@lazySingleton，NavigatorObserver）：页面 push/replace/pop 时自动 `logScreenView(route.settings.name)`。`createAppRouter` 新增 `extraObservers` 参数挂载，`app.dart` 注入 `getIt<AnalyticsRouteObserver>()`——页面浏览全自动上报，业务无需在每页手写。4 个单测全绿。

## 1. 任务目标（来自 spec）

T27.2（spec 1020-1023）：go_router 观察者集成 + 页面浏览自动上报，交付物页面埋点观察者。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 观察者 | `AnalyticsRouteObserver extends NavigatorObserver`（注入 `Analytics`） |
| didPush/didReplace | 上报新页面 `screen_view` |
| didPop | 上报返回后重新可见的上一页 |
| 过滤 | 只报 `PageRoute` 且 `settings.name` 非空（忽略弹窗/无名路由） |
| 接线 | `createAppRouter(extraObservers: [...])` + `app.dart` 注入（不影响既有 observer 测试） |

## 3. 快速上手（Quick Start）

```dart
// app.dart 已接：
createAppRouter(
  ...,
  extraObservers: [getIt<AnalyticsRouteObserver>()],
);
```
之后所有命名路由切换自动上报 screen_view（见 AppLogger 日志）。

## 5. 与 spec 的偏差与决策

T27.2 决策：用 `extraObservers` 可选参数挂载（默认空），**零破坏**既有 `app_router_test`（仍传单 observer）；页面名取 `route.settings.name`（go_router 会带路径/名称）；只报 PageRoute 避免把 Dialog/BottomSheet 误记为页面。
