## 2. 设计要点

### 2.1 静态工厂避免 builder 重复样板

```dart
abstract final class PageTransitions {
  static const Duration _defaultDuration = Duration(milliseconds: 220);

  static CustomTransitionPage<T> fade<T>({...}) { ... }
  static CustomTransitionPage<T> slideUp<T>({...}) { ... }
  static CustomTransitionPage<T> scale<T>({...}) { ... }
}
```

调用点：

```dart
GoRoute(
  path: '/login',
  pageBuilder: (context, state) => PageTransitions.slideUp<void>(
    state: state,
    child: const LoginPage(),
  ),
);
```

### 2.2 自动从 state 取 pageKey + name

```dart
CustomTransitionPage<T>(
  key: state.pageKey,
  name: state.name ?? state.fullPath,
  ...
);
```

`pageKey` 保证 Riverpod / 状态保留正确性；`name` 让 [RouterLogObserver]（T07.8）输出可读日志。

### 2.3 3 种动画的语义

| 工厂 | 动画 | 适合 |
|---|---|---|
| `fade` | 透明度 0→1 | 详情页、信息页（轻量） |
| `slideUp` | 自下向上滑入 + ease curve | 登录 / 模态对话 |
| `scale` | 0.92→1 缩放 + 淡入 | 强调内容（弹窗、新功能介绍） |
