## 2. 设计要点

### 2.1 监听四种事件

```dart
class AppProviderObserver extends ProviderObserver {
  @override void didAddProvider(...)      // 首次 read：log '[provider+]'
  @override void didUpdateProvider(...)   // 状态变化：log '[provider~]'
  @override void didDisposeProvider(...)  // 释放：log '[provider-]'
  @override void providerDidFail(...)     // 错误：log '[provider!]'
}
```

`name ?? runtimeType.toString()` 让显式命名的 Provider 有可读输出。

### 2.2 enabled 字段（不是构造参数）

```dart
@lazySingleton
class AppProviderObserver extends ProviderObserver {
  AppProviderObserver();
  bool enabled = kDebugMode;
}
```

构造函数无参 — 必须如此，否则 injectable 会去 DI 容器找 `bool` 实例并失败（同 T04.5 RetryInterceptor.random 修复模式）。

### 2.3 M11 集成预期

当前 `_log` 用 `debugPrint`。M11/T11.4 完成 `AppLogger` + Sentry breadcrumb 后，把 `_log` 改为：

```dart
void _log(String line) {
  if (!enabled) return;
  getIt<AppLogger>().d(line);
  Sentry.addBreadcrumb(Breadcrumb(message: line, category: 'riverpod'));
}
```

API 形状已为 M11 准备好，无返工。
