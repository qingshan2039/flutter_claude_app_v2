## 2. 配置摘要

### 2.1 pubspec.yaml

```yaml
dependencies:
  flutter_localizations:
    sdk: flutter
  intl: any        # 版本由 flutter_localizations 约束，用 any 避免冲突

flutter:
  generate: true   # 启用 gen-l10n
```

`intl: any` 而非固定版本：`flutter_localizations` 对 intl 有严格 pin，用 `any` 让 pub 解析到兼容版本，避免版本冲突（这是 Flutter 官方推荐写法）。

### 2.2 l10n.yaml

```yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
output-class: AppLocalizations
nullable-getter: false
```

`nullable-getter: false` → `AppLocalizations.of(context)` 返回 non-null，业务代码无需 `!`。

## 3. 实施过程的修复

首版 l10n.yaml 写了 `synthetic-package: false`，新版 Flutter 报：

```
The argument "synthetic-package" no longer has any effect and should be removed.
```

**修复**：删除该行。新版 Flutter 默认非 synthetic package，生成代码直接落到 `arb-dir`（`lib/l10n/`）。
