# T24.2 SDK 初始化分级 — 验证报告

> 任务 T24.2 / 模块 M24 隐私合规 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T24.2 实现 `SdkInitializer`（@lazySingleton）：用 `SdkComponent{name, tier, init}` 注册组件，`tier ∈ {essential, optional}`；`initialize(consentGranted:)` 总是初始化必要 SDK，**仅在同意后**初始化可选 SDK，且幂等（不重复）。满足「必要/可选分离 + 用户同意后再初始化」。4 个单测全绿。

## 1. 任务目标（来自 spec）

T24.2（spec 939-942）：必要 SDK 与可选 SDK 分离 + 用户同意后再初始化，交付物 SDK 初始化框架。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 分级 | `SdkTier.essential`（同意前可初始化）/ `SdkTier.optional`（同意后才初始化） |
| 注册 | `register(SdkComponent)`（级联 `..register`） |
| 初始化 | `initialize({required consentGranted})`：essential always + optional if consent；返回本次初始化名单 |
| 幂等 | `_initialized` 集合去重，重复调用不再执行 |
| 接入点 | bootstrap：拿到 `ConsentStore.hasAgreed(v)` 后调用 |

## 3. 快速上手（Quick Start）

```dart
getIt<SdkInitializer>()
  ..register(SdkComponent(name: 'crash', tier: SdkTier.essential, init: initCrash))
  ..register(SdkComponent(name: 'analytics', tier: SdkTier.optional, init: initAnalytics));
await getIt<SdkInitializer>().initialize(
  consentGranted: getIt<ConsentStore>().hasAgreed(kPrivacyPolicyVersion),
);
```

## 5. 与 spec 的偏差与决策

T24.2 决策：用**注册表 + 分级**框架而非硬编码 SDK 列表，业务可按需注册；`init` 为闭包，解耦具体 SDK；幂等保证多次调用安全（如同意后再调用只补可选）。与 T24.1 `ConsentStore` 协作形成「同意门」。
