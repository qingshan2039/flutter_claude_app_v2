# T34.5 微交互组件 — 验证报告

> 任务 T34.5 / 模块 M34 动效系统 / 优先级 P2 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T34.5 交付微交互组件库：`TapScale`（按下轻微缩小、松开回弹的点击反馈，`AnimatedScale` + `MotionTokens.pressable`）与 `AppearAnimation`（淡入 + 上滑入场，支持 `delay` 实现列表交错 stagger）。配合 `MotionTokens.staggerDelay(index)` 让列表项逐个出现。3 个单测全绿；showcase 含按压反馈 + 4 项交错入场 + 重播。

## 1. 任务目标（来自 spec）

T34.5（spec 1191-1194）：按钮点击反馈 + 列表项动画，交付物微交互组件库。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 按压反馈 | `TapScale{child, onTap?, pressedScale=0.96}`：onTapDown/Up/Cancel 切换 `AnimatedScale`（fast 150ms + pressable 曲线） |
| 列表入场 | `AppearAnimation{child, delay=0, duration=normal, offset=(0,0.12)}`：FadeTransition + SlideTransition |
| 交错 | 每项 `delay = MotionTokens.staggerDelay(index)`（相邻 50ms） |
| 资源安全 | `AppearAnimation` 内 `Timer` 与 `AnimationController` 在 `dispose` 取消/释放 |

## 3. 快速上手（Quick Start）

```dart
TapScale(onTap: _submit, child: const MyCard());           // 按压反馈
for (var i = 0; i < items.length; i++)
  AppearAnimation(delay: MotionTokens.staggerDelay(i), child: Row(...)); // 交错入场
```

## 5. 与 spec 的偏差与决策

T34.5 决策：用 `AnimatedScale`（隐式动画）实现 `TapScale`，比手写 `AnimationController` 更简洁且自带插值；`AppearAnimation` 用一次性 `AnimationController` + 可选 `Timer` 延迟启动以支持交错，且严格在 `dispose` 释放，避免组件测试出现「Timer still pending」。两者均消费 `MotionTokens`（pressable/emphasized/normal/staggerDelay），与全应用动效节奏统一。
