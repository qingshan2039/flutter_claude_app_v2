## 2. 设计要点

### 2.1 平台无关枚举

业务只认 `AppPermission` / `AppPermissionStatus`，不 import permission_handler。这是 T09.4 平台差异封装的基础。

### 2.2 Gateway seam（关键测试设计）

permission_handler 的 `Permission.camera.request()` 走 platform channel，unit test 不可用。引入 `PermissionGateway` 把对 permission_handler 的依赖收敛到一处：

```dart
abstract class PermissionGateway {
  Future<PermissionStatus> request(Permission permission);
  Future<PermissionStatus> status(Permission permission);
  Future<bool> openSettings();
}

@LazySingleton(as: PermissionGateway)
class PermissionHandlerGateway implements PermissionGateway { ... }  // 生产
```

`PermissionServiceImpl` 注入 `PermissionGateway`，测试传 `_FakeGateway` 返回预设 `PermissionStatus`，无需 platform channel。

### 2.3 映射函数公开（@visibleForTesting）

`mapToHandler(AppPermission) → Permission` 与 `mapFromHandler(PermissionStatus) → AppPermissionStatus` 公开，可直接单测。

### 2.4 三态 + 扩展

`AppPermissionStatusX` 提供语义辅助：
- `isGranted`：granted 或 limited（部分授权也算可用）
- `needsSettings`：permanentlyDenied 或 restricted（需引导去设置）
