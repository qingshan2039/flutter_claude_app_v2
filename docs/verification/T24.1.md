# T24.1 隐私政策弹窗 — 验证报告

> 任务 T24.1 / 模块 M24 隐私合规 / 优先级 P1 / 状态 ✅ completed / 验证 2026-05-24

## TL;DR

T24.1 实现 `ConsentStore`（@lazySingleton，持久化同意版本+时间，按版本号触发重新同意）+ `PrivacyConsentDialog`/`showPrivacyConsent`（首次启动展示、不可返回键关闭、**不同意→二次确认**机制）。SDK 分级（T24.2）据 `ConsentStore` 决定是否初始化可选 SDK（即「未同意不初始化 SDK」）。9 个单测/widget 测试全绿。

## 1. 任务目标（来自 spec）

T24.1（spec 933-937）：首次启动展示 + 未同意不初始化 SDK + 二次确认机制，交付物隐私弹窗组件。

## 2. 实际配置

| 项 | 实现 |
|---|---|
| 同意存储 | `ConsentStore`（KeyValueStorage）：`agree(version)`/`hasAgreed`/`needsConsent`/`agreedAt`/`revoke` |
| 版本管理 | `needsConsent(currentVersion)` = 未同意或同意的是旧版本 → 重新弹窗 |
| 首次展示 | `showPrivacyConsent(context, version:)`（`barrierDismissible:false` + `PopScope(canPop:false)`） |
| 二次确认 | 点「不同意」→ 切到「确认不同意？」（仍不同意=false / 返回同意=回首屏） |
| 未同意不初始化 SDK | 由 T24.2 `SdkInitializer.initialize(consentGranted: consent.hasAgreed(v))` 实现 |

## 3. 快速上手（Quick Start）

```dart
if (getIt<ConsentStore>().needsConsent(kPrivacyPolicyVersion)) {
  final agreed = await showPrivacyConsent(context, version: kPrivacyPolicyVersion);
  if (agreed) await getIt<ConsentStore>().agree(kPrivacyPolicyVersion);
}
```

## 5. 与 spec 的偏差与决策

T24.1 决策：同意状态存 `KeyValueStorage`（非敏感），按**版本号**而非布尔，满足「政策实质变更需重新告知」；弹窗双重锁死（barrier + PopScope）确保必须明确选择；二次确认用单弹窗内状态切换而非再开一个对话框，体验更连贯。
