## TL;DR

| 工具 | 配置 | 状态 |

## 3. 快速上手（Quick Start）

```bash
# flutter_gen：声明资源后生成类型安全引用
dart run build_runner build --delete-conflicting-outputs   # → lib/gen/assets.gen.dart
# 用法：Assets.images.placeholder（取代裸字符串路径）

# flutter_launcher_icons：放好 assets/flavorizr/<flavor>/icon.png 后
dart run flutter_launcher_icons -f flutter_launcher_icons-dev.yaml
```

## 5. 与 spec 的偏差与决策

T15.5 决策：(1) flutter_gen 关闭 `flutter_svg` 集成（避免为一张占位 SVG 引入运行时依赖；生成纯路径 getter）。(2) flutter_launcher_icons 只交付**配置**（三套 flavor yaml）——实际生成需各 flavor 的 1024² icon.png，由使用者提供，文档说明。(3) flutter_native_splash 沿用 M13 配置，文档补多 flavor 变体用法。
