## 2. 设计要点

### 2.1 版本号语义

- `schema_version` 字段缺失 / 0 = 全新安装
- 数值 N = 已升至 v N
- targetVersion = 期望升至的版本

### 2.2 事务化升级流程

```dart
Future<void> runIfNeeded() async {
  final meta = await Hive.openBox<dynamic>(metaBoxName);
  try {
    final current = (meta.get(_versionKey) as int?) ?? 0;
    if (current >= targetVersion) return;
    for (var v = current; v < targetVersion; v++) {
      await migrations[v](v);          // 抛错 → 跳出循环 → 不更新版本号
    }
    await meta.put(_versionKey, targetVersion);
  } finally {
    await meta.close();
  }
}
```

关键：**所有迁移成功后才写版本号**。任一迁移抛错，版本号停留在原值 → 下次启动从同一版本继续重试。

### 2.3 断言保护

```dart
assert(
  migrations.length >= targetVersion,
  'migrations 列表长度必须 ≥ targetVersion，...',
);
```

开发期防止 `targetVersion=3` 但 `migrations` 只给了 2 个的错误。

### 2.5 典型迁移示例

未来 schema 变化时追加：

```dart
final migrator = DatabaseMigrator(
  targetVersion: 3,
  migrations: <Migration>[
    (_) async {
      // v0 → v1：模板首版无操作
    },
    (_) async {
      // v1 → v2：把旧 box 'queries' 的数据迁移到新 box 'recent_queries'
      final old = await Hive.openBox<String>('queries');
      final newBox = await Hive.openBox<String>('recent_queries');
      for (final v in old.values) {
        await newBox.add(v);
      }
      await old.deleteFromDisk();
    },
    (_) async {
      // v2 → v3：清理某个废弃字段
      final box = await Hive.openBox<Map<dynamic, dynamic>>('user');
      for (final key in box.keys) {
        final value = box.get(key);
        if (value != null) {
          value.remove('deprecated_field');
          await box.put(key, value);
        }
      }
    },
  ],
);
```
